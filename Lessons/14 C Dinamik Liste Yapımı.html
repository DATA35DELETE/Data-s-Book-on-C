Dinamik Liste Yapımı

Dinamik Liste

Dinamik liste; boyutu değişebilien, eleman ekleme ve çıkarma gibi işlemleri yapabilceğimiz listelere dinamik liste denir.
Peki "dinamik ile normal listelerin arasındaki fark ne " diye sorucak olursanız işte tam da budur. Diğer programlama dillerinde(C'nin geliştirilmiş hali olan C++ bile) dinamik listeler vardır. Fakat yine C'nin manuelliği burada da kendini gösteriyor ve bizlere bir dinamik liste yapısını hazır olarak vermiyor. İşte bu gibi durumlarda kendimiz böyle bir yapı yapma durumunda kalırız.
Peki neden dinamik liste? Çünkü başta eleman sayısı belli olmayan listeleri, baştan belli etmemiz gereken normal listelerde depolaman imkansızdır. Eğer elemanların sayısı, listenin alabilceği maksimum eleman sayısından bir fazla olursa Buffer Overflow oluşur ve verileriniz hiç istemediğimiz belleğe gidebilir. İşte bunu önlemek ve sorunu çözmek için dinamik listeler kullanılır.

Linked List

Linked List yani bağlantılı liste, birbiri ardına sıralanmış veriler bütününe denir.
Bağlantılı listelerde temelde üç tür vardır.

Tek Bağlantılı Listeler

Tek bağlantılı listelerde; Elemanlarda iki veri bulunur. Kendi verisinin değeri ve kendisinin sonraki elemanı işaret eden bir işaretçi bulunur. Elemanları Struct ile tanımlanır.
Evet... Şimdi ise artık C'nin gerçek tarafını görebiliriz. Aslında evet C programalama dilinin temelini neredeyse bitirdik. Artık programalama mantığı ile konularımız ilerlemektedir. Şimdi ise yaptığım tanımı biraz daha açalım; Aslında C'de dediğimiz gibi hazır yapılar olmadığın biz yine ve yeniden kendi mantığımızı kullanarak bir yapı kuracağız. Şöyle ki bir Struct ile bir elemanı tanımlıcaz; Elemanın içeriğinin verisi ve kendisinden bir sonrakini işaret etmek üzere olan bir Pointer olucak. Daha sonra önceden öğrendiğimiz Calloc ile bellekte yer ayıracağız ve Struct'daki "Sonraki" elemanı işaret eden Pointer ile elemanlar arasında gezineceğiz. Sondaki eleman ise listenin sonunu belirtmek için NULL işaret eder.
Şimdi ise tek bağlantılı bir liste yapalım. Az önce anlattığım mantık ile bir sistem yazalım listemizi "Hello" yazdırmak için kullanalım.
#include <stdio.h>
#include <stdlib.h>

typedef struct lmn       //
{                        // Elemanlar için
    char veri;           //      Struct yapımız
    struct lmn *sonraki; //
} eleman;                //


int main()
{
    // "Hello" 5 harflik bir kelimedir. Bu yüzden 5 tane "eleman" tanımlıyoruz
    eleman *harf1 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf2 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf3 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf4 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf5 = (eleman *)calloc(1, sizeof(eleman));

    // 5 harfe değerlerini verelim \\

    harf1->veri = 'H';      // Değeri
    harf1->sonraki = harf2; // Sonraki değer

    harf2->veri = 'e';      // Değeri
    harf2->sonraki = harf3; // Sonraki değer

    harf3->veri = 'l';      // Değeri
    harf3->sonraki = harf4; // Sonraki değer

    harf4->veri = 'l';      // Değeri
    harf4->sonraki = harf5; // Sonraki değer

    harf5->veri = 'o';      // Değeri
    harf5->sonraki = NULL;  // Son değer olduğundan NULL

    // Listemiz oluşmuştur
    // Şimdi ise bastıralım

    eleman *temp = harf1; // Harfleri almak için bir "geçici" tanımlayalım. Eğer harf1 yerine harf2 alırsak ekranda "ello" yazdığını görebiliriz. Bunun sebebi yazmaya başladığı elemanın harf1 yerine harf2 olması. Dolasıyla birinci olarak tanılmadığımız "H" elemanı atlar
    while (temp != NULL) // Sonraki elemanı NULL olmadığı süreççe dön
    {
        printf("%c", temp->veri); // Temp hangi elemanda ise içindeki veriyi yaz
        temp = temp->sonraki; // Temp'i bir sonraki elemana geçir
    }

    // Ekrana yazdırdık şimdi bellek yönetimi için
    // Listedeki elemanları serbest bırakalım

    temp = harf1; // İlk harfe alıyoruz ki baştan sona doğru silelim
    while (temp != NULL)
    {
        eleman *temp2 = temp; // Temp'deki elemanı bellekten temizledikten sonra, sonraki elemana geçilemedeğinden bir tane daha temp oluşturuyoruz
        free(temp); // Mevcut tempdekini serbest bıraktık
        temp = temp2->sonraki; // Temizleme işlemi ardından sonrakine geçtik
        free(temp2); // Temp2'yi serbest bıraktık
    }
    
    return 0;
}

Çıktımız ise "Hello" olucaktır.
Şimdi ise kurduğumuz liste yapısını iyi anlamak için şöyle bir resim verebiliriz;
Bağlantılı liste yapısı gereği dağınık bir yapıdadır. Dolasıyla normal listelerdeki "*(list + i)" kullanılamaz ki bu mantık Pointer aritmatiğine dayanırken, bağlantılı listelerde Pointer aritmetiği kullanılamaz. Bunu ispatlamak için kodumuzu şöyle değiştirelim;
#include <stdio.h>
#include <stdlib.h>

typedef struct lmn
{
    char veri;
    struct lmn *sonraki;
} eleman;


int main()
{
    eleman *harf1 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf2 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf3 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf4 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf5 = (eleman *)calloc(1, sizeof(eleman));

    harf1->veri = 'H';
    harf1->sonraki = harf2;

    harf2->veri = 'e';
    harf2->sonraki = harf3;

    harf3->veri = 'l';
    harf3->sonraki = harf4;

    harf4->veri = 'l';
    harf4->sonraki = harf5;

    harf5->veri = 'o';
    harf5->sonraki = NULL;

    eleman *temp = harf1;
    while (temp != NULL)
    {
        printf("%c Harfinin tutuldugu bellek adresi => %p\n", temp->veri, temp); // Değerlerin tutulduğu "veri" kısmının bellek adresinide alalım
        temp = temp->sonraki;
    }

    temp = harf1;
    while (temp != NULL)
    {
        eleman *temp2 = temp;
        free(temp);
        temp = temp2->sonraki;
        free(temp2);
    }
    
    return 0;
}

Çıktı;
Çıktıdaki bellek adresleri farklı olasada Pointer mantığına uymamaktadır.

Çift Bağlantılı Listeler

Çift bağlantılı listeler, tek bağlantılardan farklı olarak "sonraki" mantığını ek olarak "önceki" mantığı eklenmiştir.
Şimdi ise mevcut örneğimizi "Hello" yazısını hem düz hemde tersten yazdıracak şeklinde değiştirelim. Ayrıca listenin en başındaki elemanın önceki gösterdiği eleman ise NULL olmalıdır.
#include <stdio.h>
#include <stdlib.h>

typedef struct lmn
{
    struct lmn *onceki; // Önceki özelliği
    char veri;
    struct lmn *sonraki;
} eleman;


int main()
{
    eleman *harf1 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf2 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf3 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf4 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf5 = (eleman *)calloc(1, sizeof(eleman));

    // Ek olarak önceki elemanlarıda gösterecek şeklinde düzenliyelim

    harf1->onceki = NULL; // İlk eleman olduğu için NULL
    harf1->veri = 'H';
    harf1->sonraki = harf2;

    harf2->onceki = harf1;
    harf2->veri = 'e';
    harf2->sonraki = harf3;

    harf3->onceki = harf2;
    harf3->veri = 'l';
    harf3->sonraki = harf4;

    harf4->onceki = harf3;
    harf4->veri = 'l';
    harf4->sonraki = harf5;

    harf5->onceki = harf4;
    harf5->veri = 'o';
    harf5->sonraki = NULL;

    eleman *temp = harf1;
    while (temp != NULL)
    {
        printf("%c", temp->veri);
        temp = temp->sonraki;
    }

    printf("\n");

    // Tersini yazdıralım
    temp = harf5; // Sondaki eleman ile başlıyalım
    while (temp != NULL)
    {
        printf("%c", temp->veri); // Mevcut veriyi yazdır
        temp = temp->onceki; // Öncekine geç
    }

    temp = harf1;
    while (temp != NULL)
    {
        eleman *temp2 = temp;
        free(temp);
        temp = temp2->sonraki;
        free(temp2);
    }
    
    return 0;
}

Dairesel Bağlantılı Listeler

Dairesel bağlantılı ise tek bağlantılı listelerin son elemanındaki sonraki Pointer'a, ilk elemanı işaretinin atanmış şeklidir. Görsel şekilde anlatalım;
Şimdi ise beş kere "Hello" yazacak bir sistem yazalım.
#include <stdio.h>
#include <stdlib.h>

typedef struct lmn
{
    char veri;
    struct lmn *sonraki;
} eleman;


int main()
{
    eleman *harf1 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf2 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf3 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf4 = (eleman *)calloc(1, sizeof(eleman));
    eleman *harf5 = (eleman *)calloc(1, sizeof(eleman));

    harf1->veri = 'H';
    harf1->sonraki = harf2;

    harf2->veri = 'e';
    harf2->sonraki = harf3;

    harf3->veri = 'l';
    harf3->sonraki = harf4;

    harf4->veri = 'l';
    harf4->sonraki = harf5;

    harf5->veri = 'o';
    harf5->sonraki = harf1; // Son eleman olduğuğu için, ilk elemanı işaret eder

    eleman *temp;
    for (int i = 0; i < 5; i++) // 5 kere dönecek for döngümüz
    {
        printf("\n"); // "Hello" yazıları bitişik olmaması için

        temp = harf1; // Her sereferinde harf1'den başlat
        while (temp != NULL)
        {
            printf("%c", temp->veri);
            temp = temp->sonraki;

            if (temp == harf5) // Eğer sonuncu eleman olan harf5'e geldi ise
            {
                printf("%c", temp->veri); // Son harfi yazdır
                break; // While'ı kır. Eğer konulmazsa, dairesel bir yapıda olduğuıdan döngü durmucak ve kısır döngü olucaktır
            }
        }   
    }
    

    temp = harf1;
    while (temp != NULL)
    {
        eleman *temp2 = temp;
        free(temp);
        temp = temp2->sonraki;
        free(temp2);
    }
    
    return 0;
}

Stack Liste

Bellek yönetiminde bahsettiğimiz Stack bellek alanında depolanan listelere Stack liste denir.
Stack'da mantık şudur; İlk giren son çıkar. Biz bu durumu bir elma sepeti metaforundan anlatmıştık. Şimdi ise pratik olarak görelim...
Şöyle ki bir Struct tanımlıyoruz. Struct içerisinde bir dizi ve en üstdeki elemanın Index'ini tutmak üzere bir Integer değer saklar. Ardından biz kendi yazdığımız fonksiyonlar ile işlemlerimizi gerçekleştireceğiz.
#include <stdio.h>

typedef struct
{
    int veriler[10]; // "10" Maksimum Stack listesinde yer alıcak veri
    int ustdekiEleman;
} benimStackListem; // Stack listesi için yapımız

// Fonksiyonlarımız

void stackListeOlustur(benimStackListem *lst) // Struct içerisinde veri atayamıyoruz ama"ustdekiEleman" değişkenine -1 değerini atamamız gerekiyor
{
    lst->ustdekiEleman = -1; // -1 değerini atıyoruz. Çünkü listede herhangi bir veri yok. 0 veremeyiz çünkü Index'de 1. elemana tekabul eder. Bu yüzden -1
}

// Listemizin dolu mu boş mu olduğunu kontrol etmek için bu fonksiyonu yazalım
int stackDolu_mu(benimStackListem *lst){
    if (lst->ustdekiEleman == 9) // Eğer "ustdekiEleman" maksimum değer olan 9 değerine eşit ise dolmuş demektir(0-9 arası)
        return 1;
    else // Eşit değilse dolmamış demektir
        return 0;
}

// Stack listesine üstüne veri ekleme
void stackVeriEkle(benimStackListem *lst, int veri){
    if (!stackDolu_mu(lst)) // Dolu değil mi diye kontrol edelim
    {
        lst->ustdekiEleman++; // Bir ekliyelim ki üstde ekleme yapabilelim
        lst->veriler[lst->ustdekiEleman] = veri; // Üste veri ekleme
    }
}

// Stack listesinden üstdeki veriyi çıkarma
void stackVeriSilme(benimStackListem *lst){
    if (lst->ustdekiEleman != -1) // Boş mu diye kontrol edelim
    {
        lst->veriler[lst->ustdekiEleman] = 0; // Üste veri sıfıra eşitleme yani silme
        lst->ustdekiEleman--; // Bir eksiltelim ki üstde çıkarma yapabilelim
    }
}

// Üstdeki veriyi alma
int stackVeriGetir(benimStackListem *lst){
    if (lst->ustdekiEleman != -1) // Boş mu diye kontrol edelim
    {
        return lst->veriler[lst->ustdekiEleman];
    }
}

int main(){
    benimStackListem liste; // Listemizi oluşturalım
    stackListeOlustur(&liste); // Listemizi kullanımını ayarlıyoruz

    stackVeriEkle(&liste, 6); // 6 verisini ekliyelim
    printf("En ustdeki veri; %d\n",stackVeriGetir(&liste)); // 6

    stackVeriEkle(&liste, 45); // 45 verisini ekliyelim
    printf("En ustdeki veri; %d\n",stackVeriGetir(&liste)); // 45

    stackVeriEkle(&liste, 12); // 12 verisini ekliyelim
    printf("En ustdeki veri; %d\n",stackVeriGetir(&liste)); // 12

    // Şimdi ise sırayla verileri çıkartalım
    
    stackVeriSilme(&liste); // En üstdeki veriyi çıkartalım
    printf("En ustdeki veri; %d\n",stackVeriGetir(&liste)); // 45

    stackVeriSilme(&liste);
    printf("En ustdeki veri; %d\n",stackVeriGetir(&liste)); // 6

    return 0;
}

Çıktımız;
Stack listenin kullanım alanları ise;
  • Kopyala yapıştır mantığı bu listeden gelir.
  • İnternet tarayıcılarında sayfalar arasında ileri ve geri gitmizi sağlar.

Queue

Queue ise ilk giren son çıkar prensibi ile çalışan, bellek alanlarındaki Heap'e benzer bir veri yapısıdır.
Qeueu, Stack'den farklı olarak baştaki ve sondaki elemanların Index'lerini tutan Integer'lar vardır. Ekleme için sondaki eleman ile eklenir, çıkarma ise baştaki eleman ile yapılır.
Stack ile yaptığımız örneğimizi şimdi Queue ile tekrar yapalım...
#include <stdio.h>

typedef struct
{
    int veriler[10];
    int ondeki;
    int sondaki;
} benimQueueListem; // Queue yapımız

void queueBaslat(benimQueueListem *lst){
    lst->ondeki = -1; // -1 değerini atıyoruz çünkü çıkarma işlemleri için 0'dan başlatılır. 0 tanımlamamaz
    lst->sondaki = 0; // İlk veri için 0 değeri atanır
}

int queueBos_mu(benimQueueListem *lst){
    if (lst->ondeki == lst->sondaki - 1) // Sondakinin değerinin Index'ini tutan elemanın bir eksiği öndeki değerim Index'i ile aynı ise Queue boştur
        return 1;
    else
        return 0;
}

void queueVeriEkle(benimQueueListem *lst, int veri){
    if (lst->sondaki != 9) // Dolu değil mi diye kontrol
    {
        lst->veriler[lst->sondaki] = veri; // Sona veri ekleme

        lst->sondaki++; // Bir sonraki veri için bir arttır
    }     
}

void queueVeriSil(benimQueueListem *lst){
    if (!queueBos_mu(lst)) // Boş değil mi diye kontrol
    {
        lst->ondeki++; // Bir arttıralım ki diğer veri geçersiz kılınsın
    }
    
}

int queueVeriGetir(benimQueueListem *lst){
    if (!queueBos_mu(lst)) // Boş değil mi diye kontrol
    {
        return lst->veriler[lst->ondeki + 1];
    }
}

int main(){
    benimQueueListem liste; // Listemiz
    queueBaslat(&liste); // Listemizi başlatalım

    queueVeriEkle(&liste, 6); // 6 verisini ekliyelim
    printf("Ondeki veri; %d\n",queueVeriGetir(&liste)); // 6

    queueVeriEkle(&liste, 45); // 6 verisini ekliyelim
    printf("Ondeki veri; %d\n",queueVeriGetir(&liste)); // 6

    queueVeriEkle(&liste, 12); // 6 verisini ekliyelim
    printf("Ondeki veri; %d\n",queueVeriGetir(&liste)); // 6

    // Şimdi ise sırayla verileri çıkartalım
    
    queueVeriSil(&liste); // Baştaki veriyi çıkartır
    printf("Ondeki veri; %d\n",queueVeriGetir(&liste)); // 45

    queueVeriSil(&liste);
    printf("Ondeki veri; %d\n",queueVeriGetir(&liste)); // 12

    return 0;
}

Çıktımız;
Queue'nin ise kullanım alanları;
  • CPU komut yürütme sistemi için Queue kullanır.
  • Ağ programlamada paket yönetimi için kullanılır.

Generic Liste

Generic liste, tür bağımsız listelerdir.
Biz önceden statik bir veri tipi olan(int, double, ...) listeler oluşturduk ve kurduk. Generic ise bir üst seviyeye taşıyarak tür bağımsız yani bir listede aynı anda hem Integer bir değer hem de Double bir değer tutalbilceği algoritmadır.
Mantığı ise aslen boş veri türüne ait olan void(Void'li fonksiyonlardan hatırlayabilirsiniz ki geriye hiç bir değer döndürmeyen fonksiyonlardır) veri türü ile C programlama dilinin, sorgulamaksızın verileri bir dinamik belleğe kayıt edip, Linked List ile işlem yapılmasıdır.
Şimdi ise hem bir Integer hem de bir Double veri türünden veri tutabilen bir Generic Linked listesi yazalım.
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct genericLinked
{
    void *data; // Void'li değişken
    struct genericLinked *sonraki; // Tek bağlantılı bir Linked Liste
}; // Yapımız

// Başa ekleme yapıyoruz
struct genericLinked* basaEkle(struct genericLinked* lst, void *data, int size){
    struct genericLinked *temp = (struct genericLinked *)malloc(sizeof(struct genericLinked)); // Ekleme yapacağımız liste yapısı
    
    temp->data = malloc(size); // İşte Generic bu işlem ile mümkün olur. Buradaki mantık ise "size" kadar baytı temp'in içerisindeki "data" değişkeni için bir bellek alanı oluşturuyor. Örnek Integer için 4 bayt, Double için 8 baytlık yer ayrıltılır
    temp->sonraki = lst; // Linked için sonrakini işaret edecek elemanı atuyoruz

    memcpy(temp->data, data, size); // Bu kısım ise eklenmek istenen "data"'yı temp'in data'sına kopyalayıp yapıştırıyor(Bir nevi atıyor)

    return temp; // Temp'i döndür
}

int main(){
    struct genericLinked *myList = NULL; // Generic listemiz

    int integerDegerler[1] = {12}; // Eklencek verilerimizi liste şeklinde eklemeliyiz. Yoksa program çöker
    double doubleDegerler[1] = {423.659};

    myList = basaEkle(myList, integerDegerler, sizeof(int)); // malloc ile temp->data açacağımız bellek miktarını sizeıf ile göndeririz ki hata olmasın
    myList = basaEkle(myList, doubleDegerler, sizeof(double)); // Direkt dizinin ismini yazdık çünkü doubleDegerler[0] ile doubleDegerler aynı veriyi verir. Bunun sebebi dizilerin asasen bir Pointer olmaları ve bu ifade birince Pointer'ı ifade etmekte

    printf("%f  \n", *(double *)myList->data); // Verimizi çekiyoruz. Çıktı: "423.659000"
    myList = myList->sonraki; // Sonraki veriye geç

    printf("%d", *(int *)myList->data); // Verimizi çekiyoruz. Çıktı: "12"

    return 0;
}

Çıktı;
Şeklinde olucaktır. Artık bir yapının içerisinde hem Integer hem de Double içerebiliyor.

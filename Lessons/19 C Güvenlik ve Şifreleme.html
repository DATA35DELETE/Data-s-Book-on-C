Güvenlik ve Şifreleme

Güvenlik Nedir?

Bilgisayar bilimlerinde güvenlik bilginin korunması anlamına gelir.
Güvenlik dediğimizde aslında siber güvenlik ve beyaz şapkalı korsanlar gibi kavramlarla direkt bağlanıtılıdır. Bu sayfa genel olarak nasıl güvenlikten ve C programlama dilinde ise şifreleme konularını ele alıcaktır.
C programlama dilinde ise güvenlik genellikle OpenSSL kütüphanesiyle sağlanır.

Buffer Overflow

Türkçesiyle bellek taşması; genellikle önceden belirli bir bellek alanına, alanından fazla bir veri yazılması durumunda gerçekleşen ve kimi zaman veri sızıntısına kimi zaman ise programların beklenmedik bir davranış segilemesine neden olabilir.
Örneğin biz programda yüz karakterlik bir Char dizesi için RAM'den yer tahsis edelim. Eğer biz 100 karakterden fazla bir yazı yazdırmaya çalıştığımızda gördüğümüz şey belleğin yüz karakterlik sınırıydı. Ancak fizikte enerjinin kaybolmadığı gibi veride kaybolmaz. İşte bizim orada göremediğimiz olay, Ayrılan belleğin hemen yan tarafında başka bir programa veya bizim programızın farklı işlevler için ayırdığımız alanına yazılır. Bu ne kadar normal olarak görülsede aslında programın beklenmedik davranışlarına şahit oluruz. İşte siyah şapkalı korsanlarda bu durumu bildikleri için bu saldırı tekniğini kullanırlar. Saldırı basitçe, eğer saldırı bir Web sunucusuna yapılcaksa ki Web sunucularıda aynı bizim bilgisayarlarımız gibidirler ve bellek taşması yaşayabilirler. Web sitesinin girdi kısmına sunucuya bellek taşması yaşayacak büyüklükte veri girilir. Sığıyan kısımda herhangi bir zararlı kod içermez lakin verilen taşdığı kısımda bolca zararlı kod içerir ki sızan bir veriyi siz denetleyemezsiniz. Böylelikle korsan sunucunuzda istediği gibi at koşturabilir hale gelir... Tabi günümüzde bu saldırı için bolca önlem alınmıştır.
Tabi bu durumdan korunmak için yöntemler geliştirildi ve yıllarca kullanılan yönetim olan kanarya veya çerezlerde karar kılındı. Bu korumanın üç çeşidi olsada temel amacı bellek alanlarının aralarına güvenli bir bolge oluşturmaktır.
Bu korumanın ilk çeşidi olan Null çerezi koruması, bellek alanları arasında belirli bir boyutta boş bir alan açmasıdır. Eğer bellek taşması yaşanırsa, taşan veriler o Null olan çerezlere yazılmaktadır. Çerezlerin üzerlerine bir veri yazıldığında bozulurlar ve bozuk çerez olarak anılırlar.
Diğer biri ise rastgele çerez korumasıdır. Bu koruma ise Null yerine rastgele verilenden oluşan bir güvenli alan oluşturmadır. Bellek taşması durumunda aynı şekilde güvenli alana yazılır.
Tabi bu iki koruma programların birbirlerinin bellek alanlarını işgal etmesini engeller lakin korsanların zaralı yazılım çalıştırmasını engelleyemez... İşte bu yüzden Rastgele XOR çerezleri geliştirdiler. Bu koruma ise rastgele çerez koruması gibi bir güvenli alan oluşturur lakin belirli sürelerlede XOR mantık kapısı ile veriyi kasten bozar. Böylelikle zararlı bir yazılım olsa bile artık rastgele bir sayı veya harf dizininden ibaret olur.

Girdi Doğrulama(Input Validation)

Girdi doğrulama, özellikle formatlı işlemlerde sıkça kullanılan bir yöntemdir. İşlevisi ise kullanıcı tarafından girilen veriyi gerek yazı stili gerek de bağlam olarak değerlendirmek ve uygun ise veriyi işleme katmaktır.
Bunu bir veri işleme için ön değerlendirme işlemi olarak görebiliriz. Ana işleme sık sık hata yapabilir. Gerek yanlış gerek eksik veriden bolca hatalar ve sorunlar çıkar. İşte bu gibi durumların oluşmaması için ön değerlendirme ile bu verinin ana işleme katılıp katılmacağı belirlenir.
Örnek olarak telefon numarası; Eğer kullanıcı telefon numarasını yanlış ve eksik girerse ana işlem hata vericektir. İşte bu durumda ön değerlendirmede iki ana kontorl mekanizması kullanılır. Bunlardan biri yazı sitili olarak kontrol eden Syntactic ve bağlam olarak kontrol eden Semantic'dir.
Aynı örnekten gider isek Syntactic, girilen numaranın kaç haneli olduğunu kontrol ederken, Semantic ise başı artı doksan mı veya bu numara geçerli mi? şekilde kontrol yapar. Eğer iki kontrol mekanizmadanda veri geçer ise ana işleme katılır.

OpenSSL

Kurulum

OpenSSL C programlama dilinde şifreleme için olarak tasarlanmış bir kütüphanedir.
Kütüphaneyi kurmak için Perl'i kurmamız gerekir. Perl OpenSSL'in yazıldığı dil olduğundan ihtiyaç duyulur. İlk önce Perl'i resmi sitesinden indirelim. Ardından OpenSSL'in kaynak kodunu Git aracılıyla indirelim.
        
git clone https://github.com/openssl/openssl.git
cd openssl


Ardından indirdiğimiz Perl'i kullanma vakti.
    
perl Configure mingw64 no-shared no-asm --prefix=/C/OpenSSL-x64
Bu komut OpenSSL'i derler ve C sürücüsünün OpenSSL-x64 adlı bir klasöre derlenecek dosyaları hazırlar.

Make ile derlemeden önce bağımlılıkları kuralım.
make depend

Son olarak derleyip yükliyelim.
make
make install

Uzun bir derleme ardından dosyaları hazır durumdadır.

OpenSSL-x64 adlı klasöründe bulunan tüm dosyaları MinGW64'dun klasörüne kopyalayalım. Artık kütüphanemiz hazır durumda...

Bir kod derlemek için;
gcc main.c -o main -lssl -lcrypto

Hashing

Hashing, bir matematik algoritmasıdır. Bilişimde genelde verileri benzersiz bir şifrelenmiş verilere dönüştürmek için kullanılır. İki türü vardır MD5 ve SHA256. MD5 128 bittir SHA256 adı üstünde 256 bittir.
Örnek olarak iki algoritmayıda kullanarak bir örnek yapalım.

#include <openssl/sha.h> // SHA256 için kütüphanemiz
#include <openssl/md5.h> // MD5 için kütüphanemiz
#include <string.h>
#include <stdio.h>

int main(){

    char text[] = "Data Delete"; // Orjinal veri
    unsigned char hash[SHA256_DIGEST_LENGTH]; // SHA256 ile şifrelenecek veri

    SHA256_CTX sha; // SHA256'yı tanımlama

    SHA256_Init(&sha); // Değişkenmizi SHA256 olarak başlatıyoruz
    SHA256_Update(&sha, text, strlen(text));
    // SHA256 değişkenimize veriyi veriyoruz
    // &sha; SHA256 değişkenimiz
    // text; Orjinal verimiz
    // strlen(text); Orjinal verinin uzunluğu
    SHA256_Final(hash, &sha); // Son halini(şifrelenmiş olarak) hash değişkenine atıyoruz

    printf("\"Data Delete \" SHA256 => ");
    for (size_t i = 0; i < SHA256_DIGEST_LENGTH; i++) // Her bir elemanı tek tek yazdırma 
    {
        printf("%x", hash[i]); // Şifreyi yazdırırken %x ile yazılır. Aksi takdirde anlamsız harfler çıkıcaktır. Fakat değer her çalıştırmada orjinal veri aynı olduğu süreççe şifrelenmiş veride aynı olucaktır
    }

    printf("\n");
    
    unsigned char mdHash[MD5_DIGEST_LENGTH]; // MD5 ile şifrelenecek veri

    MD5(text, strlen(text), mdHash);
    // MD5 algoritması ile şifreleme
    // text; Orjinal veri
    // strlen(text); Orjinal verinin uzunluğu
    // mdHash; Şifrelenmiş verinin atanacağı değişken

    printf("\"Data Delete \" MD5 => ");
    for (size_t j = 0; j < strlen(text); j++) // Her bir elemanı tek tek yazdırma 
    {
        printf("%x", mdHash[j]);
    }

    return 0;
}

Simetrik Şifreleme

Simetrik şifreleme veya AES, Key denilen berilli değerlerle verileri şifreleyip çözebildiğimiz bir algoritmadır.
Mantığı ise tek bir Public Key vardır. Bu Key hem kilit hem de anahtar görevi görmektedir. Basit bir örnek yapalım

#include <stdio.h>
#include <openssl/aes.h> // Kütüphanemiz

static const unsigned char key[] = {
    0x00, 0x11, 0x22, 0x33, 0x44, 0x55, 0x66, 0x77,
    0x88, 0x99, 0xaa, 0xbb, 0xcc, 0xdd, 0xee, 0xff,
    0x00, 0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07,
    0x08, 0x09, 0x0a, 0x0b, 0x0c, 0x0d, 0x0e, 0x0f
}; // Public Key'miz

int main(){

    unsigned char data[] = "Data Delete"; // Orjinal veri

    unsigned char sifrelenmis[256]; // Şifrelenecek verinin değişkeni
    unsigned char cozulmus[256]; // Şifresi çözülecek değişken

    AES_KEY enc, dec; // Şifreleyici ve çözücü iki değişken

    AES_set_encrypt_key(key, 256, &enc);
    // Şifreleyici Public Key yapar
    // key; Public Key'in verisi
    // 256; Kaç bitti olucak
    // &enc; Şifrelici olacak olan değişken
    AES_encrypt(data, sifrelenmis, &enc);
    // Veriyi şifreliyici ile şifreler
    // data; Orjinal veri
    // sifrelenmis; Şifrelenmiş verinin atanacağı değişken
    // &enc; Şifreleyici Public Key

    AES_set_decrypt_key(key, 128, &dec);
    // Çözücü Public Key yapar
    // key; Public Key'in verisi
    // 256; Kaç bitti olucak
    // &dec; Çözücü olacak olan değişken
    AES_decrypt(sifrelenmis, cozulmus, &dec);
    // Şifrelenmiş veriyi çözer
    // sifrelenmis; Şifrelenmiş veri
    // cozulmus; Çözülmüş verinin atanacağı değişken
    // &dec; Çözücü Public Key

    printf("%s", cozulmus);

    return 0;
}
        
Çıktı ise "Data Delete" olucaktır.

Asimetrik Şifreleme

Asimetrik şifrlemede ise iki farklı anahtar ile veriler şifrelenir ve çözünür.
Bu Key'lerden biri Private yani özel, diğeri ise Public yani genel Key'dir.
Genel mantık ise Public ile veri şifrelenir ve Private ile sadece Public'in şifrelidiği veriyi çözer. Bir örnek yapalım.

Her şeyden önce ilk olarak OpenSSL ile Private ve Public Key'leri oluşturalım.
openssl genrsa -out private.pem 2048
Bu komut iki bin kırk sekizlik bir Private anahtar dosyası oluşturur. Şimdi ise bu Private Key'lerden Public Key'leri bulalım.
openssl rsa -in private.pem -outform PEM -pubout -out public.pem
Artık Key'lerimiz hazır durumda

C kodlarımız;
#include <openssl/rsa.h> // RSA için ana kütüphane
#include <openssl/pem.h> // PEM yani Key dosyalarını okumak için kütüphane
#include <stdio.h>
#include <string.h>

// Key oluşturmak kolay olsun diye fonksiyon yazalım. Eğer parametresi 1 ise Public, diğer ihtimallerde Private Key oluşturur
RSA *rsaAnahtarOlustur(int isPublic)
{
    FILE *publicKeys = fopen("public.pem", "rb");
    FILE *privateKeys = fopen("private.pem", "rb");
    // Public ve Private Key dosyalarını okuma modunda aç

    RSA *rsa = RSA_new();
    // Yeni bir RSA değişkeni oluştur

    if (isPublic) // 1 ise
    {
        rsa = PEM_read_RSA_PUBKEY(publicKeys, &rsa, NULL, NULL); // Public Key'lerden birini RSA değişkenimize ayarla
    }
    else
    {
        rsa = PEM_read_RSAPrivateKey(privateKeys, &rsa, NULL, NULL); // Private Key'lerden birini RSA değişkenimize ayarla
    }

    fclose(publicKeys);
    fclose(privateKeys);

    return rsa;
}

int main()
{
    unsigned char data[2048/8] = "Data Delete"; // Orjinal veri

    unsigned char sifreliData[4098]={}; // Şifreli verinin barınacağı değişken
    RSA *publicRsa = rsaAnahtarOlustur(1); // Public bir Key oluştur
    int enc_len = RSA_public_encrypt(strlen(data), data, sifreliData, publicRsa, RSA_PKCS1_PADDING);
    // Public Key ile veriyi şifreler
    // strlen(data); Orjinal verinin uzunluğu
    // data; Orjinal veri
    // sifreliData; Şifrelenmiş verinin atanacağı değişken
    // publicRsa; Public Key RSA değişkeni
    // RSA_PKCS1_PADDING; Bu bir dolgu flag'tır. Dolgu ise her şifrelemede, şifrelenmiş veri aynı çıkmasın diye değiştiricilerdir. Güncel projeler için önerilen bu flag'tır
    
    unsigned char cozulmus[4098]={}; // Şifreli verinin çözünecek değerinin barınacağı değişken
    RSA *privateRsa = rsaAnahtarOlustur(0); // Private bir Key oluşturur
    int dec_len = RSA_private_decrypt(enc_len, sifreliData, cozulmus, privateRsa, RSA_PKCS1_PADDING);
    // Private Key ile veriyi çözer
    // enc_len; Şifreli verinin uzunluğu
    // sifreliData; Şifreli veri
    // cozulmus; Çözünecek verinin atanacağı değişken
    // privateRsa; Private Key RSA değişkeni
    // RSA_PKCS1_PADDING; Dolgu flag'ımız. Bu kısımda hangi flag ile şifrelenmiş ise o flag ile çözebiliriz. Aksi takdirde veri bozuk çıkacakır

    printf("Cozulmus veri: %s", cozulmus);

    return 0;
}

Çıktı ise;

Rastgele Sayı Üretme

C'de gerçek anlamıyla rastgele sayı üretmek istiyorusak Soduim adlı bir kütüphanin randombytes_uniform adlı fonksiyonuna ihtiyaç duyarız.
İlk olarak Sodium'u kuralım;
pacman -S mingw-w64-x86_64-libsodium

Kurulumun ardından kodumuzu yazabilir hale geliriz.
#include <stdio.h>
#include <sodium.h> // Kütüphanemiz

int main(){
    
    printf("%d", randombytes_uniform(11)); // 10 ila 0 arasında rastgele bir sayı üretir. Her çalıştırıldığında farklı sonuç verir

    return 0;
}
        
Çıktımız ise sıfır ile on arasındaki rastgele bir sayı olucaktır.

Hata Yönetimi

Hata yönetimi; bir programda bir hata oluştuğunda, o hatayı algılayıp program daha çökmeden yönetim sistemine hata yönetimi denir.
Diğer dillerde try catch gibi yapılarla hata yönetimi yapılır. Fakat C programalam dilinde bu tarz hazır yapıları bulunmadığından kendimiz bu işi halletme durumundayız. C programlama dilinde errno adı verilen bir global hata yönetim değişkeni vardır. Örneğin, dosya veya bellek tahsis işlemlerinde bir hata meydana geldiğinde, meydana gelen hata kodu errno değişkenine kayıt edilir. Biz ise mevzu bahis işlemlerin ardından errno'yu kontrol ederek "Bir hata meydana gelmiş mi?" şeklinde hata yönetimi sağlarız.
Pointer'lar sayfamızda NULL'u görmüştük. Benzer şekilde hata veren işlemlerde NULL verir fakat bir yandan da errno değişkenine hata kodlarını kayıt eder.

Hata Kodları ve Anlamları

Her bir hatanın anlamı ve kodu vardır. Şimdi ise tablo şeklinde inceleyelim.
Hata Kodu Anlamı
0 Hata Yok
1 İşlemeye İzin Verilmiyor
2 Böyle Bir Dizin veya Dosya Yok
3 Böyle Bir Süreç Yok
4 Kesintiye Uğramış Sistem Çağrısı
5 G/Ç Hatası
6 Böyle Bir Cihaz veya Adres Yok
7 Argüman Listesi Çok Uzun
8 Yürütme Biçimi Hatası
9 Geçersiz Dosya Numarası
10 Çocuk Süreçleri Yok
11 Tekrar Deneyin
12 Hafıza Yetersiz
13 İzin Red Edildi 
Pekiştirmek için bir örnek yapalım. Olmayan bir dosyayı açmaya çalışalım ve hata kodunu gözlemliyelim. Dosya işlemlerini öğrenmemiş olsak da hata yönetimi en çok bu işlemlerde yapılır. Dosya İşlemleri sayfamızda daha detaylı işleyeğiz.
#include <stdio.h>
#include <errno.h> // Kütüphanemiz

int main(){

    FILE *olmayanDosya = fopen("olmayanBirDosya.x", "r"); // Olmayan bir dosyayı açmak

    printf("Hata Kodu: %d", errno); // Hata kodumuzu konsolda yazdırlım...

    fclose(olmayanDosya); // Bellek yönetimi için dosyamzıdan çıkalım
}

Kodumuz derlenip çalıştırıldığında "Hata Kodu: 2" şeklinde bir yazı karşınıza çıkıcaktır.

Perror()

Bu fonksiyon, errno göre bizlere ekranımıza hata mesajını bastırmamızı sağlar.
Şimdi ise kodumuzu bu fonksiyonumuzu ekliyelim.
#include <,stdio.h>
#include <errno.h> // Kütüphanemiz

int main(){

    FILE *olmayanDosya = fopen("olmayanBirDosya.x", "r"); // Olmayan bir dosyayı açmak

    printf("Hata Kodu: %d\n", errno); // Hata kodumuzu konsolda yazdırlım...
    perror("Hata Mesaji"); // Hata koduna göre hata mesajını verir...

    fclose(olmayanDosya); // Bellek yönetimi için dosyamzıdan çıkalım
}

Strerror()

Bu fonksiyon ise verilen hata kodlarının, hata mesajlarının sonucunu verir.
Şimdi ise sıfırdan on üçe kadar hata kodlarının mesajlarını ekrana yazalım.
#include <stdio.h>
#include <errno.h>
#include <string.h> // Strerror için string.h kütüphanemiz de lazım olmakla

int main(){

    for (int i = 0; i <= 13; i++)
    {
        printf("%d hata kodunun mesaji: %s\n", i, strerror(i));
    }

    strerror(errno); // errno ile kullanımı

    return 0;
}

Kodumuzun çıktısı, sırasıyla hata kodları ve onuların hata mesajlarıdır.

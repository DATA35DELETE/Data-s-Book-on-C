Dosya İşlemleri

Dosya Nedir?

Dosya; bilgisayarın fiziksel diskinde bulunan verileri sanal ortamda temsil etmek için kullanılan, aksi bir durum yaşanmaz ise sounsuza kadar depolanabilen bilgilerdir.
Dosya işlemleri ise bu bilgilerin üzerinde işlem yapılması demektir.
C programlama dilinde dosya işlemleri #include <stdio.h> kütüphanesindeki "f" harfi ile başlayan fonksiyonlarla gerçekleşir.

Dosya Açma ve Kapatma

Dosya üzerinde işlem yapabilmemiz için ilk önce dosyayı açmamız gerekir. Bunun için ise fopen ile dosyamızı FILE adlı özel bir değişken türüne ait bir değişken tanımlıyoruz. Ayrıca modlar ile dosyanın üzerinde ne tür işlemler yapabilceğimizi yazıyoruz. Ayrıca dosya açma işlemi başarısız olursa fonksiyonun değeri NULL olucaktır.
FILE* file = fopen("dosyaIsmi.dosyaUzantisi", "açilmaModu");
Dosya açma modları ise aşşağıdaki tabloda, amaçlarıyla beraber verilmiştir.
Açma Kodu Amacı
r Dosyaları okumak için açar. Yoksa NULL döndürür.
rb Dosyaları Binary şeklinde okumak için açar. Yoksa NULL döndürür.
w Dosyaları yazmak için açar. Üzerine yazar. Yoksa oluşturur.
wb Dosyaları Binary şeklinde okumak için açar. Üzerine yazar. Yoksa NULL döndürür.
a Dosyaları içeriğine eklemek için açar. Yoksa oluşturur. 
Fopen dosyayı RAM'e yüklediğinden fclose ile yüklediği dosyayı RAM'de serbest bırakmamız gerekir. Bu işlem bellek yönetimi için kritik önem arz eder.
fclose(file);

Dosya Oluşturma

Dosya oluşturmak için, dosya yoksa oluşturucu yeteneğine sahip dosya açma modları kullanılır.
#include <stdio.h>

int main(){
    FILE* file = fopen("dosyaIsmi.dosyaUzantisi", "w"); // Klasörde bulunmayan bir dosya oluşturuyoruz. w, dosya yoksa oluşturma yeteneğine sahiptir

    fclose(file); // Bellek yönetimi için gereklidir

    return 0;
}

Derlenip çalıştırıldığında uygulamın bulunduğu klasörde dosyamızı görebiliriz.

Dosya Silme

Dosya silme işlemi için ise remove("dosyaIsmi.dosyaUzantisi"); fonksiyonu ile yapılır.
Şimdi ise oluşturduğumuz dosyayı silelim;
#include <stdio.h>

int main(){
    //FILE* file = fopen("dosyaIsmi.dosyaUzantisi", "w");

    remove("dosyaIsmi.dosyaUzantisi"); // Silme işlemi

    return 0;
}

Derleyip çalıştırdığımızda dosyamızın kaybolduğunu görebiliriz.

Dosya Yazma İşlemleri

Dosya yazma işlemleri, dosyanın içeriğine bilgiler yazma işlemlerine denir.
Dosyaya veri yazmak için bir çok fonksiyon bulunur. Şimdi ise teker teker tüm fonksiyonları görebilceğimiz bir kod yazalım.
#include <stdio.h>

int main(){
    FILE* file = fopen("dosyaIsmi.dosyaUzantisi", "w"); // Dosyamızı yazma modunda açalım

    fprintf(file, "Kullanıcının İmsi: %s\n", "Data"); // printf gibi dosyaya yazı yazmamızı sağlar. Ayrıca göründüğü üzere formatlı bir şekilde yazılabilir.
    fputs("Kullanıcının Soyismi: Delete", file); // fprintf'in formatsız yazdıran halidir
    fputc('\n', file); // Tek bir karakter yazar

    fclose(file);
    
    return 0;
}

Çalıştırıldıktan sonra dosyanın içeriği ise;

Dosya Okuma İşlemleri

Dosya okuma işlemleri, dosya içeriğini okuma işlemleridir.
Dosya okuma için fgets fonksiyonu vardır. Fgets ise satırdaki verilen sınır kadar okur ve verilen Char dizesine atar. Şimdi ise okuma örneğimizdeki yazdığımız bilgileri okuyalım ve konsola yazdıralım.
#include <stdio.h>

int main(){
    FILE* file = fopen("dosyaIsmi.dosyaUzantisi", "r"); // Dosyamızı okuma modunda açalım
    if (file == NULL) // Hata kontrolü
    {
        perror("HATA");

        return 1;
    }
    
    char yazilar[100]; // Okumak için Char dizesi. 100 karakterlik bir sınır koydum

    while (fgets(yazilar, 100, file) != NULL) // fgets dosyanın sonuna geldiğinde NULL döndürür.
    {
        printf("%s", yazilar); // Bulunan yazıları konsola yazdır
    }

    fclose(file);
    
    return 0;
}

Çıktımız;
Bozuk bir çıktı elde etsekte dosyamızın içeriğini bu şekilde okuruz.

Dosya Konumlandırma İşlemi

Dosya konumlandırma, dosyamızın üzerinde işlem yaparken hangi satır ve sütünda yaptığımızı ayarlamak için yapılan işlemdir.
Dosya üzerinde işlem yaparken mesela dosyaya yazı yazıyor olalım. İşlem bittiğinde o işlemin bittiği yerden diğer işlemler devam eder. Konumlandırma için fseek kullanılır.
fseek(file, kaydirilacakDeger, kaydirilcagiYer);
        
file; Konumalandırma yapılacak dosya
kaydirilacakDeger; Kaydırlacak bayt sayısı, pozitif ise ileri, negatif ise geriye olur.
kaydirilcagiYer; Kaydırmaya nereden başlıcağını belirtir.
    SEEK_END; Dosyanın sonundan
    SEEK_SET; Dosyanın başından
    SEEK_CUR; Mevcut konumundan
Şimdi ise bu özelliği kullanarak, üzerinde işlem yaptığımız dosyamızın 2. satırındaki yazıyı "Kullanıcının parası: 100" şeklinde değiştirelim.
#include <stdio.h>

int main(){
    FILE* file = fopen("dosyaIsmi.dosyaUzantisi", "w");

    fprintf(file, "Kullanıcının İmsi: %s\n", "Data");
    fputs("Kullanıcının Soyismi: Delete", file);

    printf("İşlemlerin başladığı konum: %d\n", ftell(file)); // ftell ile dosyadaki mevcut konumu öğrenebilirsiniz
    fseek(file, -31, SEEK_END); // Dosyanın sonundan 31 karakter geriye çünkü "Kullanıcının Soyismi: Delete" o kadar karakteri var. Hesaplama ise her karakter 1 bayt fakat İngilizce olmayan karakterler 2 bayt ediyor
    printf("İşlemlerin başladığı konum: %d\n", ftell(file)); // ftell ile dosyadaki mevcut konumu öğrenebilirsiniz
    
    // Yeniden yazma
    fputs("Kullanıcının parası: 100   ", file);

    fclose(file);
    
    return 0;
}

Dosyamızın içeriği;

İkili(Binary) Dosya İşlemleri

Binary dosyaları için ise "rb" ve "wb" kullanırız. Bu modlar bizlere dosyamızı ikili biçimde değer yazdırmamızı sağlarlar.
Şimdi ise Binary şeklinde bir dosyamıza "selam" yazalım ve okuyalım.
#include <stdio.h>

int main(){
    FILE *filew = fopen("binary.bin", "wb"); // Binary dosyaları .bin uzantısına sahip olmalı. Dosyamızı yazma işlemiyle açıp Binary şeklinde işlem yapıcağımızı belirtiyoruz

    fwrite("selam", sizeof(char), 5, filew);
    // "selam"; Binary dosyasına yazılacak değer. Eğer sayı yazdıracaksak (int n; &n)
    // sizeof(char); Her bir elemana ayrılacak bayt sayısı
    // 5; Tüm elemanlara ayrılacak bayt
    // file; Yazdıralacak dosya

    fclose(filew);

    FILE *filer = fopen("binary.bin", "rb"); // Dosyamızı okuma işlemiyle açıp Binary şeklinde işlem yapıcağımızı belirtiyoruz
    
    char binaryDosyasidakiDeger[6];

    fread(binaryDosyasidakiDeger, sizeof(char), 5, filer);
    // binaryDosyasidakiDeger; Çıktının atacak değişkeni. Eğer sayı yazdıracaksak (int n; &n)
    // sizeof(char); Her bir elemana ayrılacak bayt sayısı
    // 5; Tüm elemanlara ayrılacak bayt
    // file; Okunacak dosya

    printf("Binary'nin degeri; %s", binaryDosyasidakiDeger);

    fclose(filer);

    return 0;
}

Çıktımız "Binary'nin degeri; selam" olucaktır.

Linux'da Klasör İşlemleri

Klasör işlemleri, dosyaların bulunabilceği konumlara denir. Klasörün diğer ismi dizindir.
C dilinin platform bağımlığı yüzünden dosya işlemleri Linux'da ve Windows'da farklıdır.
Peki klasörleri neden kullanalım? Tabiki de gerçek hayatta olduğu gibi dosyaları sınıflandırmak ve birbirlerinden ayrımaktır. Mesela Github Repo'larına aşınaysanız README.md dsoyalarını görmüşsünüzdür. Mesela o dosyanın ismi her Repo'da aynı, her REAMDE.md dosyasınında bulunduğu Repo'da farklıdır. Aynı zamanda bir klasör içerisinde aynı isme ve uzantıya sahip iki dosya bulunamaz. İşte bu yüzden dosyaları sınıflandırmak ve düzenlemek için klasörleri kullanırız.

Klasör Oluşturma

Klasör oluşturma için Linux tarzı işletim sistemlerinde bulunan #include <sys/stat.h> kütüphenasinde bulunan mkdir fonkisiyonu ile oluşturulur. Eğer başarılı olursa sıfır, başarısız olursa eksi bir dönmektedir. Böylelikle hata yönetimi sağlanır.
mkdir("klasörİsmi", 0755);
        
"klasörİsmi"; Oluşturulacak klasörün isminin ne olucağını belirtir.
0755; Modudur. 0755 hem okuma hem yazma hem de yürütme yetkisine sahibine verirken, diğerlerine okuma ve yürütme yetkisi vermektedir.

Klasör Silme

Klasör silmek için ise #include <unistd.h> kütüphanemizde bulunan rmdir fonksiyonu kullanılır. Eğer başarılı olursa sıfır, başarısız olursa eksi bir dönmektedir.
rmdir("klasörİsmi");

"klasörİsmi"; Silinecek klasörün ismidir.

Klasör İçeriğini Listeleme

Klasör içerğini listemek için şu kodları yazarız;
#include <stdio.h>
#include <dirent.h> // Kütüphanemiz

int main(){

    struct dirent *Dirent; // Bilgileri alacağımız yapı değişkeni
    DIR *dir = opendir("klasörİsmi"); // Bilgileri alacağımız klasör. opendir, aynı fopen gibi bir Pointer döndürür ve bir akış gibi çalışır

    while ((Dirent = readdir(dir)) != NULL) // readdir ile de klasörümüz içerisindeki dosya ve klasörleri aynı fgets gibi okuyabiliyoruz
    {
        printf("%s\n", Dirent->d_name); // Yapının içerisinden d_name ile ismi alıyoruz
    }
    
    closedir(dir); // Aynı fclose gibi de dir'i kapatıyoruz

    return 0;
}

Çıktı ise(Tabi klasör içeriğini ben kendim oluşturdum);

Dosya Bilgisi Alma

Dosya bilgisini almak için aşşağıdaki kodları yazabiliriz;
#include <stdio.h>
#include <sys/stat.h> // Kütüphanemiz

int main(){

    struct stat fileStat; // Bilgileri alacağımız yapı
    stat(".logo", &fileStat); // .logo adlı dosyanın bilgilerini yapımıza aktarıyoruz

    printf(".logo dosyasının boyutu: %ld\n", fileStat.st_size); // st_size ile boyutunu alıyoruz

    return 0;
}

Çıktı ise ".logo dosyasının boyutu: 325" olucaktır.

Bu işlem ise ele aldığımız veriyi dosya mı yoksa klasör mü olduğunu kontorl etmemizi sağlar.
Şimdi ise bir önceki örneğimize ek olarak, dosya mı klasör mü sembol dosyası mı kontrol edelim.
#include 
#include 

int main(){

    struct stat fileStat;

Çalışma Dizini

Çalışan dizin ise programın dosya ve klasör işlemlerini yürüttüğü klasördür. Varsayılan olarak program kendi dizini(yani .)'yı baz alır. Ancak biz #include <unistd.h> kütüphanesinde bulunan chdir fonksiyonu kullanılır. Chdir, girilen dizini çalışma dizini haline getirir.
Şimdi ise "benimKlasör" adlı bir klasör oluşturalım, onu çalışma dizini haline getirelim ve bir dosya oluşturalım. Bakalım hangi dizinde oluştuğunu tree komutu ile görelim.
#include <stdio.h>
#include <unistd.h>
#include <sys/stat.h>

int main(){

    mkdir("benimKlasör", 0755);

    chdir("benimKlasör");

    fclose(fopen("dosya", "w"));
    
    return 0;
}

Windows Klasör İşlemleri

Şimdi ise Windows tarfına bakalım. Windows'da çoğu #include <windows.h kütüphanesinde bulunur.

Klasör Oluşturma

Klasör oluşturmak için CreateDirectoryA() komutunu kullanıyoruz.
CreateDirectoryA("klasorIsmi", NULL);
        
"klasorIsmi"; Oluşturulacak klasörün ismi.
NULL; Güvenlik paramtresi. İstemedeğimden NULL.

Klasör Silme

Klasör silmek için CreateDirectoryA fonksiyonu kullanılır.
RemoveDirectoryA("klasorIsmi");
        
"klasorIsmi"; Silinecek klasörün ismi.

Klasör İçeriğini Listeleme

Windows'da klasör içeriğini listeleme aynı Linux'da olduğu gibi bir akış gibi çalışır. FindFirstFileA ile akışı başlatır, FindNextFileA ile devam ettirir ve FindClose ile akışı sonralandırırız.
Şimdi ise Linux'daki örneği Windows'da yapalım;
#include <stdio.h>
#include <windows.h> // Kütüphanemiz

int main(){
    WIN32_FIND_DATA ffd; // Verileri çekeceğimiz yapımız
    HANDLE h = FindFirstFileA("*.*", &ffd); // Windows API'larında neredeyse her şey HANDLE adı verilen bir yapı üzerinden yürümektedir. Ayrıca ilk dosyayı almış olduk. Ayrıca yıldızlar her türlü dosyayı içeren özel filtredirler

    printf("%s\n", ffd.cFileName); // İlk dosyayı yazdırma

    while (FindNextFileA(h, &ffd)) // FindNextFileA, sonraki dosyayı başarıyla alırsa 1, almazsa 0 döner. Böylelikle bir While döngüsü kurabiliriz
    {
        printf("%s\n", ffd.cFileName);
    }
    
    FindClose(h); // Akışı kapatalım

    return 0;
}

Çıktı ise;

Dosya Bilgisi Alma

Dosya bilgisi almak için ise GetFileAttributesA komutunu kullanılırız.
Şimdi se GetFileAttributesA ile örneğimizi geliştirilem;
#include <stdio.h>
#include <windows.h> 

int main(){
    WIN32_FIND_DATA ffd;
    HANDLE h = FindFirstFileA("*.*", &ffd);

    do 
    {
        if (GetFileAttributesA(ffd.cFileName) & FILE_ATTRIBUTE_ARCHIVE) // Dosya mı?
        {
            printf("Dosya: %s\n", ffd.cFileName);
        }
        else if (GetFileAttributesA(ffd.cFileName) & FILE_ATTRIBUTE_DIRECTORY) // Klasör mü?
        {
            printf("Klasor: %s\n", ffd.cFileName);
        }

    }while (FindNextFileA(h, &ffd)); // While Do, normal While'dan farklı olarak şartı kontrol etmeden bir tur kod bloğunu çalıştırması ve daha sonra kontrol eden bir döndüdür.
    
    FindClose(h);

    return 0;
}

Çıktı ise;

Native Dosyalar

Native dosyalar, kodların bir çalıştırabilir dosya yerine işlevleri içeren bir tür dosyalara denir. Genelde Windows'da ".dll" iken Linux'da ise ".so" olmak üzere uzantıları vardır.
Native dosyalarda önce standart kütüphaneleri ve OS API'larından bahsedelim. Standart kütüphaneleri belirli yıllarda toplanan C programalama konferanslarında tartışmalar sonucu oluşan belirli kütüphanelerdir. C90, C99, C11, C17 ve C23 belirnen standartlardır. Çoğu zaman C17 veya C23 projelerde kullanılırken bazı gömülü sistemlerde C99 kullanılır. İşte bu standart kütüphanelerinden en bilinen stdio.'dır işlevi ise G/Ç olaylarını standartize etmek. Eğer öyle olmazsayda Windows ve Linux'da farklı yazdırnma komutları giriyor olurduk. Standart kütüphaneler arada bir katman görevi yaparak yazılıcının kod yazmasını kolaylaştırmaktadır. Fakat bazı işlevler(Örneğin Shared Memory) standart bir kütüphane çıkartmak hem teknik hem de pratik olarak çok zordur. O yüzden Windows'da Shared Memory için windows.h kütüphanesini kullanırkne Linux'da sys/shm.h kullanılır. İşte bu gibi kütüphanlere de OS API denir.

Linux'da Native Dosya İşlemleri

Linux'da Native dosya işlemleri için ilk öncelikle dinamik ve statik Native dosyaları anlatalım.

Statik ve Dinamik Kütüphaneler?

Statik kütüphaneler derlenen ana programa gömülen kütüphanelerdir. Yani ayrı bir dosyada depolanmak yerine ana programın içerisinde depolanırlar. Dosya uzantıları .a'dur. Avantajı ise program dizininde kütüphane dosyaları olmaz. Dezavatantajı ise de ana programın boyutu şişer.
Dinamik kütüphaneler ise statiklerin tam tersidir. Ana program içerisine gömülmek yerine ayrı bir dosya olarak depolanırlar. Dosya uzantıları .so'dur. Avantajı ise ana program güncelleme alacağı zaman kütüphaneye dokunmak gerekmez ve eğer genel yani başka programlarda aynı kütüphaneyi kullanıcak ise disk alanından tasaruf yapmamızı sağlar. Dezavantajı ise de program dizisinde, eğer büyük bir proje ise çok fazla kütüphane dosyası olur. Bu durumun diğer bir adı ise DllHell(Dll Cehennemi) adı verilir.

Statik Kütüphane Oluşturma ve Kullanımı

İlk olarak statik bir kütüphane yazalım;
main.c
#include <stdio.h>

int top(int, int); // Statik kütüphanede tanımlı fonksiyonlar
int cik(int, int);

int main(){
    printf("%d\n", top(5,5));   // 10

    printf("%d\n", cik(23, 3)); // 20

    return 0;
}


top.c
int top(int a, int b)
{
    return a+b;
}

cik.c
int cik(int a, int b)
{
    return a-b;
}


Şimdi cik.c ve top.c adlı iki kod dosyasını bir statik kütüphane haline getiriceğiz. Ardından main.c dosyamızı kütüphanemiz ile derleyip programımız elde edeceğiz.

Şimdi ilk adım olan cik.c ve top.c dosyalarını sadece derlenmiş(.o dosyaları) elde edelim.
cc -Wall -c top.c cik.c
cc; C derleyicisi. GCC'e benzer.
-Wall; Bağlama fastını yapma.
-c; Kaynak dosyaları.

Ardından derlenen dosyaları bir arşiv yapalım.
ar -cvq libkutuphanem.a top.o cik.o
libkutuphanem.a; İşlem sonucu çıkacak dosya. Kütüphane dosyasının isimlerinin her zamna başına "lib" eki getirilmelidir. Çünkü bir C standartıdır.

Sonra ranlib ile sıkıştırılan dosyayı, ana progamımın okuması için bir sembol tablosu haline getirelim.
ranlib libkutuphanem.a

Son olarak da ana programımı kütüphanemiz ile derliyelim.
cc main.c -L. -lkutuphanem -o main
-L.; Kütüphanenin dizini.
-lkutuphanem; Kütüphanenin ismi("lib" ön eki yerine "l" yazıyoruz).

Şimdi çalıştıralım.
./main

20

Dinamik Kütüphane

Aynı kodları şimdi ise dinamik bir kütüphane yapalım kullanalım.
Sadece main.c kod dosyasının içeriğini bununla değiştirelim.
#include 

extern int top(int, int); // Extern ifadesi kullanılmalıdır
extern int cik(int, int);

int main(){
   printf("%d\n", top(5,5));

   printf("%d\n", cik(23, 3));

   return 0;
}


İlk olarak statikte olduğu gibi derlenmemiş obje kodlarına ihtiyacımız var.
gcc -c -FPIC cik.c top.c

Daha sonra .so dosaysına çevirelim.
gcc -shared -o libmymath.so top.o cik.o

Ardından aynı statikte olduğu gibi kütüphanemiz ile derliyelim
gcc -o main main.c -L./ -lmymath

Sonra ise main'i çalıştırsakda hata vericektir çünkü kütüphaneler Linux'da LD_LIBRARY_PATH adlı bir değişkende aranır. Şimdi ise ekliyelim.
export export LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH

Son olarak main'i çalıştırdığımızda statik ile ayno olucaktır.
Bu sistem çalışıcaktır. Eğer LD_LIBRARY_PATH'e eklemek istemezsek #include <dlfcn.h> kütüphanesiyle dlopen, dlsym ve dlclose fonksiyonlarını kullanabiliriz. Çünkü LD_LIBRARY_PATH'e eklemek geçici bir çözümdür. Konsol kapatıldıktan sonra işlevini kaybeder.
Aynı kodlarımı kullanalım. Fakat yine main.c'nin içeriğini değiştirmemiz gerekecek.
#include <stdio.h>
#include <dlfcn.h> // Kütüphanemiz

int (*top)(int, int); // Fonksiyonlarımızı bu şekil tanımlayalım
int (*cik)(int, int); 

int main()
{
    void* ktp = dlopen("./libmymath.so", RTLD_LAZY);
    // "./libmymath.so"; Kütüphanenin ismi
    // RTLD_LAZY; Kullanım olmadığı süreççe çözümleme(Bellek yönetimi açısından)

    top = dlsym(ktp, "top");
    // tkp; Kütüphane nesnesi
    // "top"; Çözümlenmesi gereken fonksiyon ismi
    cik = dlsym(ktp, "cik");

    printf("%d\n", top(5,5));

    printf("%d\n", cik(23, 3));

    dlclose(ktp); // Kullanımı bittiği için serbest bırakıyoruz

    return 0;
}

Tekrar kütüphane ile derlediğip çalıştırdığımızda LD_LIBRARY_PATH'ye kütüphaneyi eklemizi gerek kalmadı.

ldd

ldd komutu ise Linux'da bir programın bağımlılıklarını yani ihtiyaç duyduğu kütüphanelerini göstermek için kullanılan bir araçtır.
Kullanmak için Linux terminalinden ldd main yazalım ve çıktıyı inceleyelim.
Çıktıda gördüğünüz gibi programın bağımlılıkları gözükmektedir.

Windows'da Native Dosya İşlemleri

Windows'da Native dosyalar olan .dll ve .lib dosyalar ile işlemleri gerçekleştirilir. .dll dinamik olurken .lib ise statik kütüphanedir.
Derleme ve kullanım ise Linux'la tamamiyle aynıdır. Sadece dlopen Windows'da bulunmaz. Fakat zaten Windows'da bir uygulama kütüphanesini arıyor ise kendi klasörü içerisinde aramaktadır.

Json Dosyaları

Json dosyları, .json uzantısı olan ve verileri serileştirmek için kullanılan bir dosya formatıdır. Json'nun açılımı ise JavaScript Object Notation

Json Mantığı

Json'nın mantığı ise girdiğimiz verileri aynı değişken ve dizi tanımlar gibi bir formata çevirerek hem insanlar hem de makineler tarafından kolayca okuyabilmesi sağlar. API dediğimiz sunucu ve istemci arasındaki iletişimi sağlayan, veri alışverişi yapan ara katman bile Json dosyası formatında veriyi getirir. Yani Json genel olarak kabul görmüş ve çokça kullanılan bir dosya formatıdır.

        Derlenmiş dosyaları tabiki Mingw64'e eklemeliyiz. Vcpkg'deki derlenmiş dosyalar \vcpkg\installed\x64-windows dizininde bulunur. Dizindeki tüm klasörleri kopyalayıp Msys2'deki \mingw64 dizinine yapıştıralım.

Json Dosyası OLuşturma ve Yazma

Json oluşturma ve yazmak için hem cJson API'larını hem de fopen fonksiyonunu kullanırız.
#include <stdio.h>
#include <cjson/cJSON.h> // Kütüphanemiz

int main(){
    cJSON *json = cJSON_CreateObject(); // İlk olarak Json dosyamız için JSON objesi oluşturuyoruz

    cJSON_AddBoolToObject(json, "buKosulTrue", 1);
    // json; JSON objesi
    // "buKosulTrue"; İfadenin ismi
    // 1; İfadenin değeri

    // Bu format diğer eleman ekleme fonksiyonları için geçerlidir

    cJSON_AddStringToObject(json, "kosulIsmi", "buKosul");
    cJSON_AddNumberToObject(json, "buKosulId", 326);

    char* charsJson = cJSON_Print(json); // Bu kısımda oluşturduğumuz JSON objesini, dosya olarak yazdırmak için uygun bir şekilde char dizesi haline getiriyoruz

    FILE *fjson = fopen("veriler.json", "w"); // Dosyamızı açıyoruz
    fprintf(fjson, charsJson); // Char dizesini yazdırıyoruz
    fclose(fjson);

    cJSON_free(charsJson); // Char dizesini bellek yönetimi için serbest bırakıyoruz
    cJSON_Delete(json); // JSON objemizi serbest bırakıyoruz

    return 0;
}

Aynı klasör içerisinde oluşacak dosya olan "veriler.json" içeriği;

Json Dosyası Okuma

cJson'da veri okuma ise isim-değer tabanlı arama ile veri geitirilir.
#include 6lt;stdio.h>
#include <cjson/cJSON.h>

int main(){
    FILE *fjson = fopen("veriler.json", "r"); // Mevcut veriler.json dosyasını okuma
    if (fjson == NULL)
    {
        return 1;
    }
    
    char buffer[2048]; // Maksimum çıkarılacak veri
    fread(buffer, 1, sizeof(buffer), fjson); // fread ile okuma
    fclose(fjson);

    cJSON *json = cJSON_Parse(buffer); // Okunan veriyi düzenliyor

    cJSON *kosulIsmi = cJSON_GetObjectItemCaseSensitive(json, "kosulIsmi"); // JSON objemizde ismi "kosulIsmi" olan bir değer arıyor
    if (kosulIsmi == NULL) // Eğer mevcut değil ise NULL değeri döndürür
        return 1;

    printf("kosulIsmi = \"%s\"", kosulIsmi->valuestring); // Çıkarılan veriyi ekrana yazdırma 

    cJSON_Delete(json);

    return 0;
}

Çıktı ise "kosulIsmi = "buKosul"" şeklinde olmalıdır.

Json Dosyasında Vâr Olan Veriyi Değiştirme

cJson'da bu işlemlem cJSON_ReplaceItemInObjectCaseSensitive fonksiyonu ile gerçekleştirilir.
#include <stdio.h>
#include %lt;cjson/cJSON.h>

int main(){
    FILE *fjson = fopen("veriler.json", "r"); // Mevcut veriler.json dosyasını okuma
    if (fjson == NULL)
    {
        return 1;
    }
    
    char buffer[2048]; // Maksimum çıkarılacak veri
    fread(buffer, 1, sizeof(buffer), fjson); // fread ile okuma

    cJSON *json = cJSON_Parse(buffer); // Okunan veriyi düzenliyor

    cJSON_ReplaceItemInObjectCaseSensitive(json, "kosulIsmi", cJSON_CreateString("suKosul"));
    // json; JSON objesi
    // "kosulIsmi"; Değeri değiştirilecek verinin ismi
    // cJSON_CreateString("suKosul"); Verinin yeni değeri

    char *charsJson = cJSON_Print(json);

    fjson = fopen("veriler.json", "w"); // Mevcut veriler.json yazma
    if (fjson == NULL)
    {
        return 1;
    }
    fprintf(fjson, charsJson); // Değişiklik uygunlanmış JSON objesinin char dizeli halini yazdırma

    cJSON_Delete(json);
    fclose(fjson);

    return 0;
}

veriler.json dosyasının yeni hali ise;

Xml Dosyaları

Xml dosyaları aynı Json gibi veri serileştirme ve yönetmek için kullanılan bir dosya formatıdır.Yazılma şekli olarak Html diline benzerdir. Html'deki gibi etiket değer ilişkisi ile veriler yazılır. Ağaç benzeri bir mimarisi vardır.
Xml dosyalarını okumak ve yazmak için GNOME tarafından geliştirilen libxml2 kütüphanesi kullanılır.

Libxml2 Kütüphanesini İndirme

Libxml2, Linux işletim sisteminde varsayılan olarak gelsede Windows işletim sisteminde ayrı olarak kurulması gerekir.
İndirmek oldukça basittir. Mingw64 konsolunu açalım. Ardından şu komutu çalıştıralım.
pacman -Syu mingw-w64-x86_64-libxml2

İndirmenin ardıdan kütüphanemizi kullanabiliriz.

Xml Dosyası Yazma ve Okuma

Aynı kod dosyasında hem yazma hem de okuma gerçekleştiriceğiz.
#include <stdio.h>
#include <string.h>
#include <libxml/parser.h>    // Genel kütüphanemiz
#include <libxml/xmlreader.h> // Okuma için kütüphane

int main()
{
    // OKUMA \\

    xmlDocPtr doc = xmlNewDoc(BAD_CAST "1.0"); // Xml belgeisini değişken olarak oluşturma
    xmlNodePtr root = xmlNewNode(NULL, BAD_CAST "root"); // Her bileşenin bulunacağı Root etiketi
    xmlDocSetRootElement(doc, root); // Xml belgesinin ana dizini root'a bağlama

    xmlNodePtr child = xmlNewChild(root, NULL, BAD_CAST "İsim", BAD_CAST "Data");
    // Bir xml döğümü/bileşeni
    // root; Hangi bileşenin altında yer alıcak
    // NULL; xmlNS
    // BAD_CAST "İsim"; Bileşenin ismi. BAD_CAST ifadesi ise libxml2 kütüphanesine özel bir char dizesidir
    // BAD_CAST "Data"; Bileşenin içeriği
    xmlNodePtr child2 = xmlNewChild(root, NULL, BAD_CAST "Soyisim", BAD_CAST "Delete");


    xmlNodePtr child3 = xmlNewChild(root, NULL, BAD_CAST "İletişim", NULL);
    xmlNodePtr child4 = xmlNewChild(child3, NULL, BAD_CAST "Tell", BAD_CAST "05XX XXX XX XX");
    xmlNodePtr child5 = xmlNewChild(child3, NULL, BAD_CAST "E-Mail", BAD_CAST "data.delete3509@gmail.com");
    // Bu şekil bir yapıda oluşturulabilir
    
    xmlSaveFormatFileEnc("bilgilerim.xml", doc, "UTF-8", 1);
    // Doc değişkenine eklenen bileşenleri bir .xml dosyasına yazdırma
    // "bilgilerim.xml"; Oluşturulacak dosya ismi
    // doc; Kayıt edilecek xmlDocPtr değişkeni
    // "UTF-8"; Karakter kodlama(Türkçe karakter için UTF-8 kullanılır)
    // 1; Format türü

    xmlFreeDoc(doc); // libxml2 kendi özel bellek yönetimine sahiptir


    xmlTextReaderPtr readDoc = xmlReaderForFile("bilgilerim.xml", "UTF-8", 1);
    // Bir Xml okuyucu oluşturma(Tüm okuma işlemleri için kullanılması için)
    // "bilgilerim.xml"; Okunacak .xml dosyası
    // "UTF-8"; Okuma için hangi kodlama
    // 1; Format türü

    int ret;                                        // xmlTextReaderRead fonksiyonu, sırayla tüm düğümlerde gezinmek için kullanılır. Eğer bir düğüm bulursa 1, bulamazsa yani belge bitmiş ise 0 döner. Ayrıca alt bileşenlerede erişir
    while ((ret = xmlTextReaderRead(readDoc)) == 1) // Ret değişkeni ile bu durumu kontrol ederiz
    {
        const xmlChar *nodeName = xmlTextReaderConstName(readDoc); // Mevcut bileşenin ismini alma
        int nodeTuru = xmlTextReaderNodeType(readDoc); // Bileşen tür numarasu. 1 = Bileşenin kendisi, 3 = Bileşenin değeri, 15 = Bileşenin kapanma etketi, 14 = Bileşenin kapanma etketin değeri
        const xmlChar *nodeDegeri = xmlTextReaderConstValue(readDoc); // Bileşenin değerini alma

        // Terminale, düğümün ismini ve değeri yazdıralım

        if (nodeTuru == 1)
        {   
            if (nodeDegeri == NULL)
                printf("\n");
            printf("%s", nodeName);
        }
        else if (nodeTuru == 3)
            printf(" -> %s\n", nodeDegeri);
    }
    
    xmlFreeTextReader(readDoc); // libxml2 kütüphanesinde TextReader için özel bir bellek yönetimi

    return 0;
}

Zlib Kütüphanesi

Zlib kütüphanesi, dosyaları sıkıntırmak için kullanılan bir kütüphanedir.
Peki neden dosyaları sıkıştırıyoruz. Çünkü boyutunu azaltmak için! Bu sistem genelde büyük uygulamalarda fazla disk alanı kullanılmasın diye uygulanır. Sıkıştırmak teriminin anlamı ise bir dosyanın içeriğindeki baytlar eğer bir örüntü içinde tekrarlıyorsa, o dosyayı bir formata çevirip, format okunduğunda orjinal dosyayı elde edilir. İşte bu formatlı dosyaya sıkıştırılmış dosya denir. Tarih boyunca bir çok sıkıştırma algoritması denenmiştir. Şuanda yaygın olarak kullanılan algoritma ise LZ77'dir.
Kütüphane GCC ile varsayılan olarak kurulu gelmektedir.

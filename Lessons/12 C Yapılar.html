Struct Nedir?

Scructs, C programlama dilinde özelleştirilmiş değişken türlerini oluşturmak için kullanılan bir araçtır.
Diğer modern dillerde Struct'lara benzer olarak Class'lar OOP prensibi vardır. Bu kavramların C programlama dilindeki karşılığı olarak Struct'lar vardır.
Peki Struct dediğimiz bu araç aslında ne yapıyor? Ne gibi işlerimiz için kullanıcağız? Neden kullanmalıyız? Gibi sorunların cevabı için Struct konusuna giriş yapalım...

Struct Tanımlama ve Kullanımı

Struct tanımlamak için struct anahtar kelimesini kullanmalıyzı. Ardından Struct adını ve küme parantezlerini açıyoruz. Küme parantezlerinde Struct içersinde olmasını istediğim değişkenin türünü ve ismini girip son olarak noktalı virgül koyuruz. Bu işlemi istediğiniz kadar yapabilirsiniz. Son olarak küme parantezlerini kapatıp noktalı virgülümüzü konuyoruz.
struct structIsmi{
    int s1;
    char* metin1;

    ...
};

Şeklinde formülü verebiliriz.
İsimlendirme kuralları ise değişkenlerin isimlendirme kurallarıyla aynıdır.
Değişken türümüzü oluşturmuş olduk. Şimdi ise oluşturduğumuz değişken tipimizi bir değişkene atayalım ve verileri atayıp ekrana basalım.
"kullanıcı" adlı bir Struct oluşturalım. İçersine "name", "id" ve "cash" olsun. Ardından Struct oluşturalım ve bir değişkene atayalım. Verileri dolduralım ve ekrana yazdıralım.
#include <stdio.h>
#include <string.h>

struct kullanci
{
    char name[50]; // Yeteri kadar alan açıyoruz Char'lı name değişkenimiz için
    int id;
    double cash;
};


int main(){

    // 1. Kullanıcı \\

    struct kullanci user1; // Oluşturduğumuz değişken türümüzü böyle bir değişkene atıyoruz
    strcpy(user1.name ,"Data"); // Değişkenimizin değerlerine erişmek için ismi.degerinIsmi şeklinde erişilir veya değiştirilir
    user1.id = 0;
    user1.cash = 100.03;
    
    // Yazdırma İşmemi
    printf("1. Kullanicinin ismi: %s\n", user1.name);
    printf("1. Kullanicinin id  : %d\n", user1.id);
    printf("1. Kullanicinin cash: %f\n\n", user1.cash);

    // 2. Kullanıcı \\
    
    struct kullanci user2;
    strcpy(user2.name ,"Enes");
    user2.id = 1;
    user2.cash = 45.33;
    
    // Yazdırma İşmemi
    printf("2. Kullanicinin ismi: %s\n", user2.name);
    printf("2. Kullanicinin id  : %d\n", user2.id);
    printf("2. Kullanicinin cash: %f", user2.cash);

    return 0;
}

Çıktımız ise;

Typedef İle Kullanım

Typedef'i önceki sayfalarımızda incelemiştik ki Struct ile Typedef çok kullanıldığı için yardımcı bir yapıdır.
Şimdi ise örneğimizi Typedef kullanarak tekrardan yazalım.
#include <stdio.h>
#include <string.h>

typedef struct kullanci
{
    char name[50];
    int id;
    double cash;
} users; // kullanici isimli Struct'ımızı users olarak gösterdik böylelikle


int main(){

    // 1. Kullanıcı \\

    users user1; // Typedef kullanımda farkı sadece anahtar kelime olarak struct kullanmıyoruz.
    strcpy(user1.name ,"Data");
    user1.id = 0;
    user1.cash = 100.03;
    
    // Yazdırma İşmemi
    printf("1. Kullanicinin ismi: %s\n", user1.name);
    printf("1. Kullanicinin id  : %d\n", user1.id);
    printf("1. Kullanicinin cash: %f\n\n", user1.cash);

    // 2. Kullanıcı \\
    
    users user2;
    strcpy(user2.name ,"Enes");
    user2.id = 1;
    user2.cash = 45.33;
    
    // Yazdırma İşmemi
    printf("2. Kullanicinin ismi: %s\n", user2.name);
    printf("2. Kullanicinin id  : %d\n", user2.id);
    printf("2. Kullanicinin cash: %f", user2.cash);

    return 0;
}

Çıktımız aynı olucaktır fakat kullanım ve okuma kolaylığı bakımından Typedef daha kullanışlıdır.

Struct'larda Pointer Kullanımı

Struct'larda Pointer kullanımı, tıpkı değişkenlerde Pointer kullanımı ile aynıdır.
Şimdiki örneğimizi Pointer kullanımı ile yapalım.
#include <stdio.h>

typedef struct kullanci
{
    char *name;
    int id;
    double cash;
} users;


int main(){

    // 1. Kullanıcı \\

    users user1; // Typedef kullanımda farkı sadece anahtar kelime olarak struct kullanmıyoruz
    users *user1Ptr = &user1; // Tanımladığımız user1'i user1Ptr işaretçisine atadık
    (*user1Ptr).name = "Data"; // Güvenli olması için user1Ptr'deki değerlere parantez içersinden erişilir
    (*user1Ptr).id = 16;
    (*user1Ptr).cash = 100.03;
    
    // Yazdırma İşmemi
    printf("1. Kullanicinin ismi: %s\n", (*user1Ptr).name);
    printf("1. Kullanicinin id  : %d\n", (*user1Ptr).id);
    printf("1. Kullanicinin cash: %f\n\n", (*user1Ptr).cash);

    return 0;
}

Çıktımız;
Mantık olarak değişen bir kısım yoktur. Sadece yöntem değiştirmiş olduk. Fakat Pointer kullanımı bizlere ok operatörü(->) kullanmamızı sağlar.

Ok(->) Operatörü

Ok operatörü bir tire(-) ve bir büyüktür(>) işaretlerinden oluşur.
Ok operatörü, Struct'larda ve Union'larda içlerindeki değerlere erişebilmek için kullanılan bir operatördür. Şü şekilde kullanılır;
*structIsmi -> structinIcerisindekiDegerIsmi = deger;
Şimdi ise verilere erişme kısmında ok operaötürünü kullanalım.
#include <stdio.h>
#include 

typedef struct kullanci
{
    char *name;
    int id;
    double cash;
} users;


int main(){

    // 1. Kullanıcı \\

    users user1;
    users *user1Ptr = &user1;
    user1Ptr -> name = "Data";
    user1Ptr -> id = 16;
    user1Ptr -> cash = 100.03;
    
    // Yazdırma İşmemi
    printf("1. Kullanicinin ismi: %s\n", user1Ptr -> name);
    printf("1. Kullanicinin id  : %d\n", user1Ptr -> id);
    printf("1. Kullanicinin cash: %f\n\n", user1Ptr -> cash);

    return 0;
}

İç içe Struct'lar

İç içe olma durumu, bir Struct içersinde başka bir Struct'ın verilerine erişebilmek demektir.
Örnek olarak şimdi örneğimize birde "ebeveynler" adlı bir Struct daha oluşturalım "kullanici" ile iç içer olsunlar. "ebeveynler" Struct' içerisinde ise anaAdi ve babaAdi yer alsın.
#include <stdio.h>

typedef struct ebeveynler{
    char *anaAdi;
    char *babaAdi;
} ebeveynler;

typedef struct kullanci
{
    char *name;
    int id;
    double cash;
    ebeveynler kullanicininEbevenyleri; // İç içe tanımlama için tanımlamadan önce yukarıda tanımlanmalıdır. Ardından bu şekilde iç içe olma durumu gerçekleşir
} users;


int main(){

    // 1. Kullanıcı \\

    users user1;
    users *user1Ptr = &user1;
    user1Ptr -> name = "Data";
    user1Ptr -> id = 16;
    user1Ptr -> cash = 100.03;

    user1Ptr -> kullanicininEbevenyleri.anaAdi = "Database"; // Erişmek için; *x -> y.a
    user1Ptr -> kullanicininEbevenyleri.babaAdi = "Computer";

    // Yazdırma İşmemi
    printf("1. Kullanicinin ismi: %s\n", user1Ptr -> name);
    printf("1. Kullanicinin id  : %d\n", user1Ptr -> id);
    printf("1. Kullanicinin cash: %f\n\n", user1Ptr -> cash);

    printf("1. Kullanicinin ana adi: %s\n", user1Ptr -> kullanicininEbevenyleri.anaAdi);
    printf("1. Kullanicinin baba adi: %s\n", user1Ptr -> kullanicininEbevenyleri.babaAdi);

    return 0;
}

Çıktımız ise;
Şeklinde kullanımı gerçeklir.

Union

Union, Struct'lara benzer olucak şekilde lakin içerisindeki değerlerin türlerinin en büyüğü kadar bellekte yer tahsis eden bir yapıdır.
Aynı Struct'lar gibi oluşuturul fakat anahat kelime olarak union kullanılır ve noktalı virgülden hemen önce gözükücek ismi yazılır. Ayrıca bir değişkene atanması gerekmez, direkt gözüken ismi üzerinden erişilir. Yani Static'tir.
union unionIsmi{
    int s1;
    char* metin1;

    ...
} gozukecekIsmi;

İçlerindeki değerlere erişmek için;

gozukecekIsmi.s1;
Union, içindeki değerlerin türlerinin en büyüğü kadar bellekte yer tahsis ettiğini söylemiştik. Bu her ne kadar bellek tasarufu konusunda iyi olsa da bellek taşma durumlarında yanıltıcı veriler döndürme durumu olabilir. Union bellekte gösterimsel olarak üst üstü şeklinde duruyor. Aslında bir hüclerinin içinde aslında Uniom'nun içersinde tanımlanan değerler kadar veri tutuluyor. Bu durum Struct'larda geçerli değildir. Struct'larda daha çok yan yana olma durumu vardır. Yani her veri için kendi hücresi vardır.
Şimdi bir örnek yapalım. Örneğim bizlere aynı değerlere sahip bir Struct ve Union'nun bellekte ne kadar yer kapladıklarını yazan bir program olsun.
#include <stdio.h>

union ornekBirUnion
{
    int s1;
    int s2;

    char c1;
    char c2;

    long long ll1;
    long long ll2;
} ornekBirUnion;

typedef struct ornekBirStruct
{
    int s1;
    int s2;

    char c1;
    char c2;

    long long ll1;
    long long ll2;
} ornekBirStruct;


int main(){

    printf("Struct'in kapladigi alan -> %d\n", sizeof(ornekBirStruct));
    printf("Union'un kapladigi alan -> %d\n", sizeof(ornekBirUnion));

    return 0;
}

Çıktımız;
Aynı verilere sahip olmalarına rahmen Union 8, Struct 32 bayt yer ayrımıştır.

Enum

Enum, diğer yapıların aksine özel değer isimleri oluşturmak için kullanılır.
Enum'daki amaç ise kodun okunabirliğini ve kullanabirliğini artırmaktır.
Struct gibi tanımlanır. Tek fark ise değerler atanılabilir.
enum modlar{
    ZIYARETCI = 1,
    KULLANICI = 2,
    OPERATOR = 3 // Sonda virgül eklenmez
};

Enum olduğu belli olsun diye içerisindeki değerlerin isimleri büyük harfle yazılır.
Şimdi ise bir kullanıcı modu ayırt etme programı yazalım. Verdiğim örnekdeki gibi bir Enum oluşturalım ve If ve Else If'lerle ayırt edelim.
#include <stdio.h>

enum modlar{
    ZIYARETCI = 1,
    KULLANICI = 2,
    OPERATOR = 3
};

int main(){

    enum modlar kullaniciMods;
    kullaniciMods = ZIYARETCI; // Bu kısımdaki veriyi değştirerek, çıktıdaki değişimi gözlemleyebilirsiniz

    if (kullaniciMods == ZIYARETCI)
    {
        printf("Kullanici ziyaretcidir.\n");
    }
    else if (kullaniciMods == KULLANICI)
    {
        printf("Kullanici normal kullanicidir.\n");
    }
    else if (kullaniciMods == OPERATOR)
    {
        printf("Kullanici operatordur.\n");
    }

    return 0;
}

kullaniciMods'un değeri değiştikçe çıktıda değişecektir.
Ayrıca Enum'larda Typedef'de kullanılabilir. Şimdi örneğimizi Typedef'li yazalım.
#include <stdio.h>

typedef enum modlar{
    ZIYARETCI = 1,
    KULLANICI = 2,
    OPERATOR = 3
} mods;

int main(){

    mods kullaniciMods; // Sadece mods yazmamız yeterli artık
    kullaniciMods = ZIYARETCI;

    if (kullaniciMods == ZIYARETCI)
    {
        printf("Kullanici ziyaretcidir.\n");
    }
    else if (kullaniciMods == KULLANICI)
    {
        printf("Kullanici normal kullanicidir.\n");
    }
    else if (kullaniciMods == OPERATOR)
    {
        printf("Kullanici operatordur.\n");
    }

    return 0;
}

Log Sistemi

Loglama Nedir?

Log türkçesiyle günlük; Bir programın hangi zamanlarda nasıl davrandığını veya hangi kısımda hata çıkardığını görmek için yazılımcılar tarafından kullanılan bir program izleme tekniğidir.
Peki neden biz Log ile programı izlememiz gerekir? Çünkü programın hatalarını görmek ve iyileştirmek için tabi! Düşünün C dili ile kodlanmış programların çökme sebeblerinin çoğunluğu NULL ile işlemlerden kaynaklanmaktadır. Gerek dosya açarken gerek dinamik bellek açarken komutlar şartlardan dolayı başarısız olabilirler. Sonucunda ise program ya çöker ya da beklenmedik davranışlar sergiler. Genelde programda çökerken herhangi bir mesaj vermeden sessizce ölür. İşte bu gibi durumlarda Log ile programın çalışma sürecinde bizlere gerek konsol gerek dosyaya programın durumunu yazar. Tabi bu otomatik olmaz biz yazılımcı olarak önceden ön gördüğümüz veya sebeb olabilcek kod parçacıklarının içerisine Log kodlarını yerleştiririz. Böylelikle program çökerse neden çöktüğünü yerleştirdiğimiz kodlar sayesinde öğrenebiliriz.

Log Seviyeleri

Log seviyeleri, Log bilgisinin ne kadar önemli veya neyi ve nerden geldiğini ifade eden seviyelerdir. Genel olarak yedi tane seviye vardır.
Log Seviyesi Açıklama
INFO Programda bir işlem sonucunu belirtir. Önrek olarak bir fonksiyonun başarılı bir şekilde çalıştığını ifade edebilir.
DEBUG Genel olarak geliştiriciler içindir. Bir fonksiyona hangi verilerin verildiği veya sonucu ifade eder.
TRACE DEBUG'tan daha detaylı ve adım adım işlemlerin nasıl yürüdüğünü görebiliriz. Eğer kapalı kaynak bir uygulama yazıyorsak ve kodların çalınması mühim bir durumsa, uygulamanın yayımlandığı sürümde bulunması tavsiye edilmez.
WARNING Bir fonksiyonun istenen bir durumu yerine getireme durumunda bu seviye kullanılır. Örnek olarak dizini yanlış verilmiş bir Fopen fonksiyonun sonucu Null olarak döndürmesi gibi...
ERROR Program çökmez ama istenmeyen şekilde davranmasıuna yol açan bir durum gerçekleştiğinde kullanılır. Örnek olarak Stack Overflow örnek verilebilir.
FATAL Eğer programın çöküceği bir durum oluşursa bu seviye kullanılır. Örnek olarak herhangi bir işlemde Null kullanmak genelde programın çökmesi ile gerçekleşir.

Loglama Formatı

Geler geçer bir format olmasada çoğunlukla kullanılan bir Loglama formatı vardır. Format: İlk olarak yıl ay gün, saat dakika ve saniye: satır numarası: Log seviyesi: Log mesajı şeklinde kullanılır.
2026/05/23 22:56:04, 74 [LOG SEVİYESİ] Log mesaji

Konsola Loglama

Konsola Loglama için bu örnek kodu kullanabiliriz.
#include <stdio.h>
#include <string.h>
#include <time.h>

int main(){
    time_t guncelZaman = time(0); // Güncel zamanı alma
    char *guncelZamanStr = ctime(&guncelZaman);
    for (int i = 0; i < strlen(guncelZamanStr); i++)
        if (guncelZamanStr[i] == '\n')
            guncelZamanStr[i] = '\0';
    // Güncel zamanı alıp gereksiz olan "\n" elemanını silelim

    char *LogSeviyesi = "INFO"; // Log seviyemiz
    char *LogMsg = "Suanda bu log konsola loglanmistir"; // Loglama mesajımız

    printf("%s [%s] %s\n", guncelZamanStr, LogSeviyesi, LogMsg); // Formatlı bir şekilde konsola yazdırma

    return 0;
}

Çıktı ise;

Dosyaya Loglama

Dosyaya Loglamak için aynı örneğimizi dosyaya Loglıcak şekilde değiştirelim.
#include <stdio.h>
#include <string.h>
#include <time.h>

int main(){

    FILE *log = fopen(".log", "w"); // Log dosyamız olacak dosyayı açalım

    time_t guncelZaman = time(0);
    char *guncelZamanStr = ctime(&guncelZaman);
    for (int i = 0; i < strlen(guncelZamanStr); i++)
        if (guncelZamanStr[i] == '\n')
            guncelZamanStr[i] = '\0';

    char *LogSeviyesi = "INFO";
    char *LogMsg = "Suanda bu log konsola loglanmistir";

    fprintf(log,"%s,%d [%s] %s\n", guncelZamanStr, __LINE__, LogSeviyesi, LogMsg); // Fprintf ile dosyaya formatı yazalım

    fclose(log);

    return 0;
}

Loglama Kütüphanesi Yazma

Evet... O kadar öğrendik şimdi ise gerçek bir ürün çıkartma vakti!
Şimdi bir Loglama kütüphanesi yazacağız. Ben şu özellikleri olmasını istiyorum; Tüm Loglama sistemini tek bir Struct ile yönetmeli ve yürütülmelidir. Kullanıcıya iki farklı seçenek olarak, konsol mu yoksa bir dosyaya mı kayıt edilceğini ".init" fonksiyonu ile belirlemeliyim. Kütüphanede kesinlikle asenkron olmalı ki ana programı etkilemesin. Kütüpaheneyi tek bir başlık dosyası olarak tasarlacağım. Böylelikle kolay bir kullanım sağlıcak. Ayrıca platform bağımsız şekilde kodlamalıyım.
Son olarak bu kütüphaneyi Github sayfamda paylaşacağım.
Evet yol haritası hazır ise artık başlayabiliriz.

void dlogger_init(dlogger* dlggr ,int logOf, char* logFileName){ // Ana yapıyı başlatma fonksiyonu

    if (logOf == logOfConsole) // Eğer konsola Loglama olucaksa
    {
        dlggr->logEntry = logOfConsole; // Konsola Loglancağını belirt
        memset(dlggr->logFileName, 0, strlen(dlggr->logFileName)); // logFileName boşalt
    }
    else // Bir dosyaya Loglanacaksa
    {
        dlggr->logEntry = logOfFile; // Dosyaya Loglanacağını belirt
        strcpy(dlggr->logFileName, logFileName); // logFileName Loglanacak olan dosyanın ismini ayarla
    }

    if (dlggr->logEntry == logOfFile) // Eğer dsoyaya loglanacaksa
    {
        fclose(fopen(logFileName, "w")); // Dsoyayı açma moduna aç ve kapat
    }
 }

DWORD WINAPI dlogger_log_info_thread(LPVOID fileNameMsgFormat) // Ayrı Thread'e çalışıcak olan fonksiyon
{
    const time_t crrctTime = time(0); // Güncel zamanı al
    char* crrctTimeStr = ctime(&crrctTime); // Güncel zamanı Char dizesine çevir
    for (size_t i = 0; i < strlen(crrctTimeStr); i++) // Char dizesine verirken gelen gereksiz \n karakterini sil
        if (crrctTimeStr[i] == '\n')
            crrctTimeStr[i] = '\0';
    
    char* fileNameMsgFormat2 = fileNameMsgFormat; // dlogger_log_info'dan gelen formatı bir değişkene ata

    short int avabialeFileName = 1; // formatı ayrımak için bir koşul belirle. 1 ise filename yaz, 0 ise msg'e yaz

    char filename[102400]; // Yazılacak olan dosyaynın ismi. Eğer konsola yazılacak ise boş kalıcaktır
    char msg[102400]; // Yazılacak olan mesaj

    for (size_t i = 0; i < strlen(fileNameMsgFormat2); i++) // Formatı ayırmak için For döngüsü ile parçaları ayırıyoruz
    {
        if (fileNameMsgFormat2[i] == '|') // Eğer karakter | ise
            avabialeFileName = 0; // 0 yap ki gire kalan kısım filename yazılmasın ve msg kısmına geçsin. Eğer konsola yazılacak ise format gereği ilk karakter | olduğundan filename'e yazılmadan direk msg kısmına geçer
        if (avabialeFileName) // avabialeFileName 1 ise
            filename[strlen(filename)] = fileNameMsgFormat2[i]; // Gelen karakteri filename'deki uygun karaktere yerleştir
        else // 0 ise
            if (fileNameMsgFormat2[i] != '|') // | karateri hariç
                msg[strlen(msg)] = fileNameMsgFormat2[i]; // Gelen karateri msg'deki uygun karaktere yerleştir
    }

    if (filename[0] == '\0') // Eğer filename ilk karateri Null ise ki ilk karater Null ise filename tamamiyle boş demektir
    {
        printf("%s [%s] %s\n", crrctTimeStr, "INFO", msg); // Log formatını konosla yazdır
    }
    else // Eğer değilse
    {
        FILE *log = fopen(filename, "a"); // log dosyasını ekleme modunda aç
        
        fprintf(log,"%s [%s] %s\n", crrctTimeStr, "INFO", msg); // Formatı dosyaya yaz

        fclose(log); // dosyayı kapat
    }
    
    snprintf(fileNameMsgFormat2, strlen(fileNameMsgFormat2), "%c", '\0'); // Bellek sızıntısı yaşanmasın diye fileNameMsgFormat2'deki tüm karakterleri Null yapıyoruz
}

// Info seviyesi için fonksiyon
int dlogger_log_info(dlogger* dlggr ,char *msg){

    char fileNameMsgFormat[102400]; // Format için değişken oluştur

    if (dlggr->logFileName[0] != '\0') // Gelen yapının logFileName'i boş değil ise
    {
        strcat(fileNameMsgFormat, dlggr->logFileName); // İlk olarak logFileName'i yazdır
        strcat(fileNameMsgFormat, "|"); // Format için ayırıcı olan | karakterini yazdır
        strcat(fileNameMsgFormat, msg); // Mesajı yazdır
    }
    else // Boş ise
    {
        strcat(fileNameMsgFormat, "|"); // Ayrıcı karakteri yazdır
        strcat(fileNameMsgFormat, msg); // Mesajı yazdır
    }
#ifdef WIN32 // Windows'a isek
    DWORD threadId; // Thread için Id
    HANDLE threadHandle = CreateThread(NULL, 0, dlogger_log_info_thread,(LPVOID)(fileNameMsgFormat), 0, &threadId); // Thread'i oluşturur
    if (threadHandle == NULL) // Eğer başarısız olursa
    {
        printf("[DLOGGER] DLOGGER ERROR: LOG DEBUG BASARISIZ!\n"); // Hata mesajı
 
        return -1; // Hata kodu
    }

    CloseHandle(threadHandle); // Thread açıcıyı kapat
#else

    pthread_t pt1; // Thread'in değişkenini oluştur

    pthread_create(&pt1, NULL, dlogger_log_info_thread, fileNameMsgFormat); // Thread'i oluştur

#endif
    
    return 0; // Tüm işlemler başarılı ise 0 döndürerek fonksiyonun başarılı olduğunu söyler
}

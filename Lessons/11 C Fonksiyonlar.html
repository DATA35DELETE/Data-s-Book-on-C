Fonksiyonlar

Fonksiyon Nedir?

Fonksiyonlar, programlamada çalıştıralablir kod bütünlerdir.
Fonksiyonlar, kodlarımızı daha iyi yönetmemizi ve düzenlememizi sağlayan yapıladır. Bir çok yerde karşımıza çıkmakta olan fonksiyonlar; String ve dosya işlemleri gibi hazır durumdada bulanabilirler.
Fonksiyonlarda dikkat edilmesi gereken kısım ise çağrılıcak satırdan önce tanımlanması veya tanıtılması gerekir. Yoksa program "implicit declaration of function" hatasını vericektir.
Fonksiyon tanımlamak için;

donusVeriTipi fonksiyonIsmi(<parametreler>)
{ // Kod bloğu başlangıcı

    // Kodlar...

} // Kod bloğu bitişi


Şeklinde tanımlanır.
Şimdi bir iki artı iki işleminin sonucu ekrana yazdıran bir program yazalım.
#include <stdio.h>

int ikiArtiIki(){ // Fonksiyonumuz
    
    printf("2 + 2 = %d\n", 2 + 2); // İşlemimiz
}

int main() {
    ikiArtiIki(); // Fonksiyonu çağırdık

    return 0;
}

Çıktımız "2 + 2 = 4" olucaktır.
Bu örnek bir önden tanımlı bir fonksiyon örneğiydi. Şimdi ise önden tanıtımlı örneği görelim.
#include <stdio.h>

int ikiArtiIki(); // Fonksiyonumuzu programa tanttık

int main() {
    ikiArtiIki(); // Fonksiyonu çağırdık

    return 0;
}

int ikiArtiIki(){ // Tanıttığımız fonksiyonu tanımladık
    
    printf("2 + 2 = %d\n", 2 + 2); // İşlemimiz
}

Çıktımız aynı olucaktır. Fakat kodsal olaral mevzu bahis fonksiyonumuzu, çağrıldığı kısımdan sonra tanımlamış olduk. Fakat yine önden tanıtım yapmamız gerekti.
İsimlendirme kuralları ise değişkenlerin isimlendirme kuralları ile aynıdır.

Main Fonksiyonu

Main fonksiyonu programın başlangıç kısmıdır ve bir projede tek bir Main fonksiyonu yer almalıdır. Eğer bir projede Main fonksiyonu yazılmaz ise program hata vericektir. Yani bir nevi ilk kodların çalıştırıldığı fonksiyondur.

Void'li Fonksiyonlar

Void'li fonksiyonlar, çağrıldıklarında bir sonuç vermeyen fonksiyonlardır.
Şimdi ise ekrana "Hello World" yazısını yazdıran bir Void fonksiyon yazalım.
#include <stdio.h>

void sayHelloWorld() // Fonksiyonumuz
{
    printf("Hello World\n");
}

int main() {
    sayHelloWorld(); // Fonksiyonu çağırdık

    return 0;
}


Çıktımız "Hello World1 olucaktır.

Return'lü Fonksiyonlar

Return'lü fonksiyonlar ise çağrıldıklarına bir sonuc veren fonksiyonlardır. Void fonksiyonlar aksine bir değer verirler. Değer verme ise Return anahtar kodu ile sağlanır.
Şimdi ise "Hello World" yazısını şimdi bir fonksiyon aracılığı ile bir değişkene atayalım ve Main'den ekrana bastıralım.
#include <stdio.h>

char* getHelloWorld() // Fonksiyonumuz
{
    return "Hello World"; // Verilen değerimiz
}

int main() {
    char *yazi = getHelloWorld(); // Fonksiyonu çağırdık ve değişkenimize atadık
    
    printf("Fonksiyondan alinin deger: %s", yazi); // Fonksiyondan alınan değeri yazdırdık

    return 0; // Main return'u aynı zamanda Main'nin dönüş değeridir
}

Çıktımız "Fonksiyondan alinin deger: Hello World" olucaktır.

Parametreli Fonksiyonlar

Paramtreli fonksiyonlar ise fonksiyonun parantezlerinde istenen verilerle alınır. Fonksiyon çağrılırken değerler parantezlere yazılır. Sırayla atanır. Aynı zamanda atanan değerler, orjinal değişkenlerin kopyasıdır.
Şimdi ise iki tane paramtre alan ve toplama yapan bir fonksiyon yazalım. Birinci paramtreyi sonucu Pointer aracılığıyla atayan, ikinci ise toplanan olarak kullanılır.
#include <stdio.h>

void topla(int *taban, int toplanan) // Fonksiyonumuz
{
    *taban += toplanan;
}

int main() {
    int x = 15; // Taban olucak değişkenmize 15 değerini atadık
    
    topla(&x, 6); // Fonksiyonumuzu çağralım. Birinci paramtre Pointerlı olduğundan ampersend'li yani bellek adresini gönderdik
    
    printf("Islemin sonucu = %d", x); // İşlemlerin ardından x'i ekrana yazdıralım

    return 0;
}

Çıktımız "Islemin sonucu = 21" olucaktır.

Özyenilemeli Fonksiyonlar

Bu fonksiyonlar ise fonksiyon içersinde kendini tekrar çağıran fonksiyonlara denir.
Döngü ile yaptığımız birden ona kadar ekrana yazdırma örneğimizi özyenilemeli fonksiyonlarda yapalım.
#include <stdio.h>

int sirala(int *taban) // Fonksiyonumuz
{
    *taban += 1;
    
    printf("%d\n", *taban);
    
    if(*taban >= 10)
        return 0; // 10'a geldiğinde fonksiyonu sonlandır
    else
        sirala(taban);
}

int main() {
    int x = 0;
    
    sirala(&x); // Fonksiyonumuzu çağrılarım

    return 0;
}


Çıktımız birden ona kadar sayılar olucaktır.

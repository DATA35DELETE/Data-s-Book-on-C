HTTP İstekleri Yönetimi

HTTP Nedir?

HTTP, internette veri iletişimin en temel ve en çok kullanılan bir protokoldur. Amacı ise internette makinelerin birbirleriyle iletişimini sağlamasıdır. Genellikle bu işlem HTML sayfalarında görüntüleme ve link gibi yapılarda kullanılmaktadır.
Peki neden HTTP kullanmalıyız? Çünkü internetten veri çekmek için biçilmiş kaftandır. Göstereceğim üzere bu tarz işler için kullanılan bir hava durumu verisini çekeceğimiz bir site üzerinden de anlaşılcağı üzere, HTTP'yi internetten veri çekeceğimiz sırada kullanıcağız.

Libcurl Kütüphanesi

Libcurl, HTTP istekleri için kullanılan bir kütüphanedir.
Libcurl, hem Linux hem de Windows'da kurulu olarak gelir. Derliceğimiz programlar -lcurl ile derlenir.

GET İsteği

GET isteği sunucudan veri almak istediğimiz zaman kullandığımız bir HTTP yöntemidir.
GET, genellikle tarayıcılarda bir setinin HTML kodlarını çekmek veya bir sunucudaki verileri almak için kullanılır. Genellikle formatlı ise de bir Json verisi olarak dönmektedir.
O zaman GET ile bir önceki sayfamızın içeriğini çekelim.
#include <curl/curl.h>
#include <stdio.h>

int main()
{
    CURL* curlEntity = curl_easy_init(); // CURL işlemleri için bir değişken oluşturalım ve onu başlatalım
    
    if (curlEntity) // Eğer başarısız olmazsa
    {
        curl_easy_setopt(curlEntity, CURLOPT_URL, "https://data35delete.github.io/Data-s-Book-on-C/Lessons/21%20C%20Veritabanı%20İşlemleri.html"); // Bu kısımda curlEntity'e GET yapacağı sitenin linkini veriyoruz.

        // curl_easy_setopt; Genel bir fonksiyondur. curlEntity için ayarları ayarlar.CURLOPT_URL bizlere bu ayarlamanın URL üzerine olucağını belirtir

        curl_easy_perform(curlEntity); // Son olarak curlEntity'i çalıştırıyoruz
    }

    curl_easy_cleanup(curlEntity); // İşimiz bittiğinde curlEntity serbest bırakalım

    return 0;
}

Çalıştırdığımızda konsolda bir önceki sayfanın html kodlarını görebilirsiniz.
Peki ya bir dosyaya kayıt etmek istersek?

#include <curl/curl.h>
#include <stdio.h>

size_t curlCallback(void* data, size_t boyut, size_t verininBoyutu, void* stream) 
// Curl'den gelen verileri almak için 4 adet paramtre ile alırız.
// data; Gelen verinin ham versiyonudur
// boyut; Gelen verinin boyutur
// verininBoyutu; Gelen verinin tüm boyutudur
// stream; Akışı temsil eder
{
    FILE* out = fopen("site.html", "ab"); // site.html adlı dosyaya kayıt ediceğiz. Ayrıca ikili ekleme modunda açıcağız

    char temp[2048]; // 2048 karakterlik bir geçici değişken oluşturduk ki bozulmaların önünde geçelim

    snprintf(temp, verininBoyutu, "%s", data); // Gelen ham veriyi Char dizesi ve sınırlı şekile yazdık. Bunun sebebi gelen veride Char dizelerinin bittiğini ifade eden Null terminatörü(\0) bulunmaması ve bu Char dizesi ile işlemlerde öngürülemez sonuçlar vermesidir. Son satırların Null olmaması içinde 1 ekledik

    fwrite(temp, sizeof(char), verininBoyutu, out); // Verileri yazdırdık

    return boyut * verininBoyutu; // Formul ile çıkmalıyız. Bir nevi gelecek verilerin, önceki verinin önüne geçmemesi için bir "bitti" mesajını vermek gibi
}

int main()
{
    CURL* curlEntity = curl_easy_init();
    
    if (curlEntity)
    {
        curl_easy_setopt(curlEntity, CURLOPT_URL, "https://data35delete.github.io/Data-s-Book-on-C/Lessons/21%20C%20Veritabanı%20İşlemleri.html");

        curl_easy_setopt(curlEntity, CURLOPT_WRITEFUNCTION, curlCallback); // Bu ayarlama ile curlCallback fonksiyonumuzu gelen verilerin gönderilceği fonksiyon olarak ayarlarız

        curl_easy_perform(curlEntity);
    }

    curl_easy_cleanup(curlEntity);

    return 0;
}

Eğer "out.html" dosyasını tarayıcıda açarsanız karşınıza beyaz bir ekranda bir önceki sayfanın içeriğini görebilirsiniz.
Şimdi de Json formatında alalım. Yalnız bunun için https://httpbin.org adlı bir siteden test gerçekleştiriceğiz. O zaman hadi yapalım.
        
#include <curl/curl.h>
#include <stdio.h>

int main()
{
    CURL* curlEntity = curl_easy_init();
    
    if (curlEntity)
    {
        curl_easy_setopt(curlEntity, CURLOPT_URL, "https://httpbin.org/get?name=datadelete"); // /get kısmı bizim bir GET işlemi gerçekleştirceğimizi söylüyoruz. Soru işaretinden sonra ise veri ismi = veri değeri şekilinde format gönderilir. Ardından cevap Json olarak gelir

        curl_easy_perform(curlEntity);
    }

    curl_easy_cleanup(curlEntity);

    return 0;
}

Çıktı ise;
Bu çıktıda "args" kısmı bizim hangi argumanları ve argumanların değerlerini gösteren bir liste vardır. Bu liste bize bağlıdır ve değişkendir.
Headrs kısmı bizim bağlandığımız sistemin bilgilerini içerir. Accept; değeri "*/*", yani her türlü sistemi kabul ettiğini söyler. Host; verinin geldiği sunucudur. X-Amzn-Trace-Id ise bizlere özel tanımlanmış bir etikettir. Her çalışmada değişkenlik gösterir.
Origin; Sunucunun IP numarısıdır.
Url; Gönderilen Url'nin geri dönüşüdür.
Şuan bunları tanıttım fakat diğer tüm sitelerde bu şekilde çalışmaz. Bu bilgiler https://httpbin.org sitesi için geçerlidir.

POST

POST, sunucuya veri göndermek için kullanılan bir HTTP yöntemidir.
Httpbin üzerinden POST yaptığımızda bize aslında geri sanki GET atmışız gibi bir veri döndürür. Fakat normal şartlarda bu durum diğer sunucularda geçerli değildir.
Şimdi ise Httpbin'e bir POST isteği gönderelim.

#include <curl/curl.h>
#include <stdio.h>

int main()
{
    CURL* curlEntity = curl_easy_init();
    
    if (curlEntity)
    {
        curl_easy_setopt(curlEntity, CURLOPT_URL, "https://httpbin.org/post"); // Httpbin'nin POST kımına erişelim

        curl_easy_setopt(curlEntity, CURLOPT_POSTFIELDS, "name=data&project=datasbookonc"); // POST isteği olarak data verisini data, project verisini de datasbookonc değerini değiştirceğimizi söyleyeb bir POST yazdık. Ardından POST modunda curlEntity'e tanıttık

        curl_easy_perform(curlEntity);
    }

    curl_easy_cleanup(curlEntity);

    return 0;
}

Çıktı ise;
Çıktıda "form" kısmında POST olarak attığımız verileri görebilirsiniz.

HTTPS ve SSL

HTTPS, HTTP'nin güvenli halidir. Peki neden? Çünkü HTTP verileri getiriyor güzel, fakat getirirken şifresiz bir şekilde getiriyor. İşte bunu önlemek için SSL sertifikalar ile getirilen ve götürülen verilerin korunumu sağlanmış oluyor. Yani veriler uçtan uca şifrelenmiş bir biçimde gidip geliyor.

Libcurl'de Hata Yönetimi

Libcurl'de hata yönetimi, CURLcode adlı bir Enum tarafından sağlanır. Her Libcurl fonksiyonu sonucunda bir CURLcode döndürür. Eğer hatasız bir işlem olursa geri dönüş tipi sıfır olur. Fakat işlem hata alırsa sıfırdan farklı olarak, hataya bağlı bir hata kodu döndürülür. Hata kodları ise curl_easy_strerror metoduna paramtre olarak verilir ve verilen hata kodunun hangi anlama geldiğini bizlere bir Char dizesi olarak döndürür.
Şimdi bu bilgiyi örneğimize uygulayalım;

#include <curl/curl.h>
#include <stdio.h>

int main()
{
    CURLcode sonuc; // CURLcode'ların atanacağı değişken
    CURL* curlEntity = curl_easy_init();
    
    if (curlEntity)
    {
        sonuc = curl_easy_setopt(curlEntity, CURLOPT_URL, "https://httpbin.org/post");
        if (sonuc != 0) // Eğer sıfırdan başka bir değer dönerse ki bu hata demektir
        {
            printf("%s\n", curl_easy_strerror(sonuc));
        }
        

        sonuc = curl_easy_setopt(curlEntity, CURLOPT_POSTFIELDS, "name=data&project=datasbookonc");
        if (sonuc != 0)
        {
            printf("%s\n", curl_easy_strerror(sonuc));
        }

        sonuc = curl_easy_perform(curlEntity);
        if (sonuc != 0)
        {
            printf("%s\n", curl_easy_strerror(sonuc));
        }
    }

    curl_easy_cleanup(curlEntity);

    return 0;
}

Artık kodumuz bir hata ile karşılaşırsa, hata mesajını ekrana yazdırıcaktır.

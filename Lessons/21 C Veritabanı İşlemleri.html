Veritabanı İşlemleri

Veritabanı Nedir?

Veritabanlar, biçimlendirilmiş veri depolama yapılarıdır.
Evet geldik internetin veri depolarına! Veritabanları bizler için aslında kritik konular diyebiliriz. Çünkü biz genelde veriler ya bir değişkende ya bir dosyada yada bir json dosyasında tuttuk. Fark etti iseniz bu depolama şekli hiç verimli değildir. Sürekli veriyi al parçala anlamlı hale getir işle ve uygun olan kısmı geri koy şekilde verimsiz işlemler yaptık. Veritabanlarında ise sadece veriyi al, işle ve geri gönder gibi basit bir döngü ile veri depolamayı inanılmaz kolaylaştıran yapılardır. Tabiki bizim C programlama dili gibi veritabanlarıylada printf veya if gibi komutlarla konuşamayız. Veritabanları için özel olarak tasarlanmış olan SQL dilini kullanırız...
Peki neden veritabanları bizim için çok önemli? Az önce bahsettiğim gibi bir veriyi depolamak veritabansız çok zahmetlidir. Örneğin bir veriyi dosyada depoladığımızda formatsız ve verimsizdir. Düşünün bir dosyada binlerce veri var, ama biz özel bir veri istiyoruz. Normal şartlarda o dosyadaki tüm verileri teker teker okuyup "İstenen veri o mu?" diyerek verileri elememiz gerekirdi. Ama veritabanları ve SQL sayesinde bu durumu bizim yerimize SQL'in kendisi yaparak bizlere kullanım kolaylığı sunar. İşte teker teker çekmek yerine "WHERE name="data"" örnek bir koşullu ifade ile "name" değişkeni "data" olan veriyi kolaylıkla çekebiliriz.

SQLite Nedir?

SQLite bizlere veritabanlarını bir dosya ile kullanmamızı sağlayan bir veritabanı uygulamasıdır.
SQLite bizlere sağladığı avantaj şudur; Diğer veritaban uygulamaları ayrı bir sistemde çalışırlar ve biz dosya olarak göremeyiz. Diğer bir özelliği ise SQLite aksine çok fazla kurulum ve kütüphane bağlama gerektirir. Başka olarak da diğer veritabanları paralı ve işlemletim sistemine özeldir. Fakat SQLite hem Windows hem Linux hem Android için sürümleri vardır. Yani Cross-Platform'dur.

Kurulum

SQLite'ı Windows işletim sistemine kurmak için MinGW konsolunda bu komutu çalıştıralım;

pacman -S mingw-w64-x86_64-sqlite3

İndirmeden ardından artık kullanabiliriz. Derlerken ise;

gcc main.c -o main -lsqlite3

Bağlantı Kurma

SQLite bir veritabanına bağlanmak için sqlite3_open ile yapılır. sqlite3_close ile kapatılır.
Örnek bir kod yazalım;

#include <stdio.h>
#include <sqlite3.h> // Kütüphanemiz

int main()
{
    sqlite3 *veritabani; // Veritabanı değişkenimiz
    int q1 = sqlite3_open("veritabanim.db", &veritabani);
    // Veritabanı bağlantısı açar
    // "veritabanim.db"; Veritabanı değişkene tanımlanacak veritabanı dosyası
    // &veritabani; Veritabanı değişkeni

    if (q1) // İşlem eğer başarısız olursa sqlite3_open 1 döner
    {
        printf("SQLite veritabanini acamadi");
    }
    
    sqlite3_close(veritabani); // Bağlantıyı kapatır

    return 0;
}

Çıktı olarak bizlere "veritabanim.db" adlı bir dosya oluşturur.

Tablo Oluşturma

Normal şartlarda tablodan önce veritabanı oluşturulur ardından tablo oluşturulur. Bu işlemler tabi SQL dilinde yapılır. Fakat Sqlite, sqlite3_open dediğimizde aslında arka planda çalıştırılan SQL komutu create database dbIsmi budur. Bu işlemin bu fonksiyonla beraber yapıldığı bilinmesi önemlidir. Tablo oluşturma için ise create table tblIsmi(veriler...) bu SQL komutu kullanılır.
Tablo ise bizler için veri depolayan yapılardır.
Az önceki örneğimize şimdi bir tablo oluşturalım.

#include <stdio.h>
#include <sqlite3.h> // Kütüphanemiz

int main()
{
    sqlite3 *veritabani;
    int q1 = sqlite3_open("veritabanim.db", &veritabani);

    if (q1)
    {
        printf("SQLite veritabanini acamadi");
    }

    char* hataMesaji; // Eğer işlem hata verir ise hata mesajının kayıt edilceği değişken
    sqlite3_exec(veritabani, "create table kisiler(id int, name varchar(256), surname varchar(256))", 0, 0, &hataMesaji);
    // SQL komutu çalıştırmamızı sağlar
    // veritabani; Veritabanı değişkeni
    // "create table kisiler(id int, name varchar(256), surname varchar(256))"; SQL komut ifadesi. İfade de "kisiler" adlı bir tablo oluşturuyor ve sırayla id, name ve surname adlı üç tane sütün koyuyor
    // 0; Callback. sqlite_exec ile geri veri döndüren bir SQL komutu yazarsak diye çalıştırılacak olan bir fonksiyon sunar
    // 0; Birinci elemanın Callback çağrısı
    
    // &hataMesaji; Hata mesajının kayıt edilceği değişken
    if (hataMesaji[0] != '\0') // Hata mesajının ilk harfi boş değil ise
    {
        printf("HATA: %s", hataMesaji); // Hatayı yazdır
    }
    
    sqlite3_close(veritabani);

    return 0;
}

Böylelikle bir tablo oluşturmuş olduk.

Veri Sorgulama

Veri sorgulamak yani veri çekmek için SQL komutlarından SELECT * FROM tableIsmi şeklinde çağrılır. Şimdi bunu C kodlarında SQLite ile yapalım. Ayrıca sqlite_exec, veri sorgularken Callback yapısı ile verileri satır satır çağırır ve Callback'deki parametreler aracılıyla sorgulanır. Her bir veri için Callback çağrılır.
        
#include <stdio.h>
#include <sqlite3.h>
#include <string.h>

int sqlVeriAliciFonk(void* bosVeri, int sutunSayisi, char** veriler, char** sutunIsmileri) // sqlite3_exec'nin Callback fonksiyonu
{
    for (size_t i = 0; i < sutunSayisi; i++) // For döngüsü ile her bir veriyi sütunuyla beraber konsola yazdırıyoruz
    {
        printf("%s = %s\n", sutunIsmileri[i], veriler[i]);
    }

    return 0;
}

Güvenli Sorgu Yazma

Evet... Şimdi günveli sorgu yazma dediğimiz kavram aslında kötü niyetli insanların "SQL Injection" yani SQL kötü parça enjekte edilmesi saldırısını engellemek için ortaya atılmış bir kavramdır.
Peki biz neden SQL komutlarımızı "güvenli" şekilde yazmalıyız. Çünkü veritabanımızın veya tablomuzun bir anda toz olup gitmesin diye! Şuanda pek fazla görülmesede eski dönemlerde bir çok veritabanı ile çalışan sistemlerde bu saldırı çok popülerdi. Bu saldırının temel aldığı en büyük açık aslında dilin ta kendisiydi. SQL yapısı geriği hiç sorgulamayan ve direkt çalıştıran bir dildir. Yani zayıf bir dildir. Şuan günümüzde pek fazla olmasada Hacker'ler bir veritabanını patlatmak isterlerse arama veya bir giriş sayfasına DROP DATABASE Main -- yazıp bütün veritabanı anında silebiliyorlardı. Kodu anlamak gerekirse "DROP DATABASE Main" kısmı zaten Main veritabanını düşür demek, "--" kısmı ise "Bu komuttan sonrasını yorum satırına al" diyerek geri kalan sorguyu çalıştırtmadan Main veritabanını düşmüş olur.
Güvenli sorgu yazmak için Sqlite'nın içerisindeki sqlite3_prepare_v2 komutu ile yazılır. Güvenli sorguda verileri direkt Char dizelerine yazmak yerine, onların yerine tutacak şekilde soru işareti(?) konulur ve numaralandırma ile veriler güvenli şekilde sqlite3_bind komutlarıyla konulur. Numalandırma soldan sağa doğru birden başlıyarak otuz iki bin yedi yüz altmış altıya kadar devam eder.
Evet... teori bu kısma kadar. Şimdi pratik yapalım. Güvenli bir sorgu ile tablomuza bir veri ekliyelim.

#include <stdio.h>
#include <sqlite3.h>
#include <string.h>

int sqlCallbackFonk(void* bosVeri, int sutunSayisi, char** veriler, char** sutunIsmileri)
{
    for (size_t i = 0; i < sutunSayisi; i++)
    {
        printf("%s = %s\n", sutunIsmileri[i], veriler[i]);
    }

    return 0;
}

int main(){

    char* hataMesaji;

    sqlite3 *db;
    sqlite3_open("veritabanim.db", &db);

    sqlite3_exec(db, "create table kisiler(id int, name text, surname text)", 0, 0, &hataMesaji);
    if (strncat(hataMesaji, '\0', 0))
    {
        printf("HATA: %s", hataMesaji);
    }

    sqlite3_exec(db, "insert into kisiler(id, name, surname) values(0, 'Data', 'Delete')", 0, 0, &hataMesaji);
    if (strncat(hataMesaji, '\0', 0))
    {
        printf("HATA: %s", hataMesaji);
    }

    sqlite3_exec(db, "insert into kisiler(id, name, surname) values(1, 'Miku', 'Hastune')", 0, 0, &hataMesaji);
    if (strncat(hataMesaji, '\0', 0))
    {
        printf("HATA: %s", hataMesaji);
    }

    sqlite3_exec(db, "insert into kisiler(id, name, surname) values(2, 'Teto', 'Kasane')", 0, 0, &hataMesaji);
    if (strncat(hataMesaji, '\0', 0))
    {
        printf("HATA: %s", hataMesaji);
    }

    sqlite3_stmt *sql; // Güvenli sorgu için değişkenimiz
    char sqlString[] = "insert into kisiler(id, name, surname) values(?, ?, ?)"; // String şeklindeki sorgumuz. ? işaretleri yerine verilerimizi yerleştiriceğiz

    sqlite3_prepare_v2(db, sqlString, -1, &sql, 0);
    // Güvenli sorgu değişkenimizi başlatır
    // db; Veritabanımız
    // sqlString; String şeklinde sorgumuz
    // -1; Sorgu ne kadar olucak. -1 değeri otomatik olarak ayarlanacak demektir
    // &sql; Güvenli değişkenimiz
    // 0; Hata mesajları. Şimdilik es geçtim

    sqlite3_bind_int(sql, 1, 3);
    // Sorgumuza Integer değeri ekler
    // sql; Güvenli sorgu değişkeni
    // 1; Kaçıncı numaradaki kısım
    // 3; Konulucak değer
    sqlite3_bind_text(sql, 2, "Luna", 1024, 0);
    // Sorgumuza String değeri ekler
    // sql; Güvenli sorgu değişkeni
    // 2; Kaçıncı numaradaki kısım
    // "Luna"; Konulacak değer
    // 1024; Konulacak String ifadenin uzunluğu
    // 0; UTF-16 ile kodlama şartı. UTF-16 ile işlem yapmadığımız için 0 yaptım
    sqlite3_bind_text(sql, 3, "Delete", 1024,0);

    char* gvnlSql = sqlite3_expanded_sql(sql); // Güvenli sorgumuzu normal String'e çeviriyoruz

    sqlite3_exec(db, gvnlSql, 0, 0, 0);

    sqlite3_exec(db, "Select * from kisiler", sqlCallbackFonk, 0, 0);

    sqlite3_close(db);

    return 0;
}

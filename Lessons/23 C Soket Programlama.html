Soket Programlama

Soket Nedir?

Soket, bir bilgisayarda iletişim kanalı açıldığında, IP adresi ve port numarasının yan yana yazılma biçimidir. IP adresi bir bilgisayarın internet ağlarını arasında kimlik görevi görürken, port numarası ise bilgisayarın içerisindeki telefonlar gibidir. Örnek olarak bir bilgisayarın 192.172.0.5 adresli bilgisayardaki 52. telefonunda bağlantı açtığımızda bize verilen bilgi "192.172.0.5/52" olucaktır. Biz o bilgsayara iletişim kuracağımız zaman bu soket ile bağlantı kurulacak ve veri alışverişi gerçekleşecektir.

TCP ve UDP Farkları

TCP, TCP bir ağ protokoldur ve Dünya çapında sıklıkla kullanılan bir ağ protokuludur. Özelliği ise veri paketçiklerinin yolda değişmediklerinin garantisini vermektedir. Calışma mantığı ise sunucu-istemci mimarisi ile çalışmaktadır. Modeli, bir veri gönderlicek ise ilk önce sunucu-istemci arasında bağlantı kurulur ve istemci veriyi gönderir. Veri sunucuya ulaştığında, sunucu istemciye bilgi vererek bilginin geldiğini söyler. Arıdından aralarında bilginin değiştirilmediğini doğrular ve veri güvenli bir şekilde iletilmiş olur.
UDP ise TCP'nin bir katmanıdır ve bazende sadece UDP kullanılır. UDP TCP'nin veri iletimiyle sorumlu olan kısmıdır. UDP'nin TCP'den farklı olarak herhangi veri kontrol mekanizması bulunmamaktadır ve TCP'de bulunan Handshake(El sıkışma, TCP'deki veri kontrol mekanizmasına denir) mantığı bulunmaz. Avantaj olarak UDP TCP'ye göre daha hızlıdır ancak verilerin değiştirilip değiştirilmediğini garanti etmez. TCP internet trafiği yaparken, UDP TCP kadar internet trafiği yapmaz.
TCP genelde statik mesajlar için kullanılır. E-posta, telefon mesajları ve internet verileri gibi çoğu bilgi TCP ile iletilir. UDP ise daha çok gerçek zamanlı video ve ses verisi göndermek için kullanılır.

TCP Soketi ile İletişim

TCP sunucu-istemci mantığı ile çalıştığı için iki dosya olucaktır. Biri server.c diğeri ise client.c. İlk olarak server.c'i yazalım.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include <winsock2.h> // Window'da soket açmak için kullanılan genel kütüphane

int main()
{   
    WSADATA wsa; // WSADATA ile soket işlemleri için bir değişken oluşturuyoruz
    WSAStartup(MAKEWORD(2,2), &wsa); // İşlevlerin çalışması için bu değişkeni başlatıyoruz

    struct sockaddr_in serverAddr; // Server bilgileri için yapı oluşturuyoruz
    int serverSoket; // Server için bir akış değişkeni tanımlıyoruz. BU soket işlemleri için aslında bir nevi ID belirlemek gibi bir işlemdir

    serverSoket = socket(AF_INET, SOCK_STREAM, 0); // serverSoket'i socket işlevi ile TCP olarak tanımlıyoruz

    memset(&serverAddr, 0, sizeof(serverAddr)); // Bellekte bazen veriler karmaşık olarak ayrılabilir. O yüzden memset ile yapıyı sıfırlıyoruz
    serverAddr.sin_addr.S_un.S_addr = inet_addr("127.0.0.1"); // IP adresi olarak 127.0.0.1 tanımlıyoruz. Aslında bu IP tüm bilgisayarlarda "Lokal IP" yerine geçen bir IP'dir
    serverAddr.sin_family = AF_INET; // AF_INET olarak ayalıyoruz ki bu soketin hep IP'si hem de portu olduğunu ifade eder
    serverAddr.sin_port = htons(1234); // Portunu 1234 olarak htons ile ayarlıyoruz

    bind(serverSoket, (struct sockaddr*)&serverAddr, sizeof(serverAddr));
    // Soket bigilerini soket akışlarına aktaran fonksiyondur
    // serverSoket; Bağlanacak soket
    // (struct sockaddr*)&serverAddr; Bağlanan soket bilgilerini içeren yapı
    // sizeof(serverAddr); Bilgilerin büyüklüğü

    listen(serverSoket, 5);
    // Soketleri dinler, veri kabul eden recv için önemlidir
    // serverSoket; Dinlenen soket
    // 5; Dinleme modu

    int clientSocket; // Client'dan gelecek olan Client soketi
    char gelenVeri[1024]; // Gelen verileri saklamak için bir değişken

    while (1) // Ana döngü, döngü içerisinde Server'a gelecek istekleri kabul eden veya geri bir değer gönderen tüm işlemler bu kısımda olur.
    {
        clientSocket = accept(serverSoket, NULL, NULL);
        // Server soketinden gelen veriler client soketine aktarır. Gelen veriyi kabul eder. İnternetten gelen tüm veriler aslında bir Node yapısında olup, her veriyi sırayla kabul etmeli ve işlemeliyiz
        // serverSoket; Server soketinin soketi

        memset(gelenVeri, 0, 1024); // Bir önceki veriden temizlemek için
        recv(clientSocket, gelenVeri, 1024, 0);
        // Gelen veriyi bir değişkene tanımlar
        // clientSocket; Gelen verinin Client soketi
        // gelenVeri; Kayıt edilecek değişken
        // 1024; Kayıt edilecek verinin boyutu. Yetersiz gelirse Stack Overflow yaşanması muhtemeldir
        // 0; Güvenlik ayarları. Şuanlık varsayalında

        printf("Client'dan gelen veri: %s\n", gelenVeri); // Veriyi konsola yazdırma
    }   
}

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include <winsock2.h>

int main(){

    WSADATA wsa;
    WSAStartup(MAKEWORD(2,2), &wsa);

    struct sockaddr_in serverAddr;
    SOCKET serverSoket;

    serverAddr.sin_addr.S_un.S_addr = inet_addr("127.0.0.1");
    serverAddr.sin_family = AF_INET;
    serverAddr.sin_port = htons(1234);

    serverSoket = socket(AF_INET, SOCK_STREAM, 0);

    // Server soketi için işlemleri yapıyoruz...

    connect(serverSoket, (struct sockaddr*)&serverAddr, sizeof(serverAddr));
    // Server'a bağlanır
    // serverSoket; Server soketi
    // (struct sockaddr*)&serverAddr; Server bilgileri
    // sizeof(serverAddr); Serveri bilgilerinin boyutu

    listen(serverSoket, 5);

    send(serverSoket, "Selam Server!", 1024, 0);
    // Server'a veri gönderir
    // serverSoket; Server soketi
    // "Selam Server!"; Gönderelecek veri
    // 1024; Gönderelecek verinin boyutu
    // 0; Güvenlik ayarları. Şuanlık varsayalında

    return 0;
}

UDP ile birer örnek yapalım.
Windows için;

server.c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include <WinSock2.h>

int main(){

    WSADATA wsa;

    struct sockaddr_in serverAddr;
    int serverSoc;

    WSAStartup(MAKEWORD(2,2), &wsa);

    serverSoc = socket(AF_INET, SOCK_DGRAM, 0);
    // UDP de SOCK_STREAM yerine SOCK_DGRAM kullanılır

    serverAddr.sin_addr.S_un.S_addr = inet_addr("127.0.0.1");
    serverAddr.sin_port = htons(1234);
    serverAddr.sin_family = AF_INET;

    bind(serverSoc, (struct sockaddr*)&serverAddr, sizeof(serverAddr));

    char veri[1024];

    while(1)
    {
        printf("Client'dan veri bekleniyor...\n");

        memset(veri, 0, 1024);

        int len = sizeof(serverAddr);

        recvfrom(serverSoc, veri, 1024, 0, (struct sockaddr*)&serverAddr, &len);
        // UDP portu için veri almak fonksiyonu. UDP'de TCP gibi connect yoktur çünkü connect TCP'deki Handshake mantığına denk gelir
        // serverSoc; Okunun soket
        // veri; Verinin kayıt edilecek değişken
        // 1024; Kayıt edilecek verinin boyutu. Az gelirse Stack Overflow ihtimal
        // 0; Güvenlik ayarları. Şuan varsayılan güvenlik ayarlarındayız
        // (struct sockaddr*)&serverAddr; Server soketi bilgileri
        // &len; Server soketi bilgilerinin boyutu

        printf("%s\n", veri);
    }

    return 0;
}

client.c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include <WinSock2.h>

int main(){

    WSADATA wsa;

    struct sockaddr_in outServerAddr;
    int outServerSoc;

    WSAStartup(MAKEWORD(2,2), &wsa);

    outServerSoc = socket(AF_INET, SOCK_DGRAM, 0);

    outServerAddr.sin_family = AF_INET;
    outServerAddr.sin_port = htons(1234);
    outServerAddr.sin_addr.S_un.S_addr = inet_addr("127.0.0.1");

    struct sockaddr_in inClientAddr;
    int inClientSoc;    

    char veri[1024] = "Hey selam ben UDP ile iletisim kuran Client!";

    printf("Server'a veri gönderiliyor...\n");

    int len = sizeof(outServerAddr);

    sendto(outServerSoc, veri, 1024, 0, (struct sockaddr*)&outServerAddr, len);
    // UDP Server'ına veri göndermek için kullanılır. UDP'de TCP'deki connect yoktur. Çünkü connect TCP'deki Handskake denk gelir
    // outServerSoc; Server'ın soketi
    // veri; Gönderelicek veri
    // 1024; Gönderelicek verinin boyutu
    // 0; Güvenlik ayarı
    // (struct sockaddr*)&outServerAddr; Server soketi bilgileri
    // len; Server soketinin bilgilerin boyutu

    return 0;
}

Çok İstemcili Server

Çok istemcili Server, birden fazla soketi olan Server'ladır.
Aynı anda iki farklı Server soketini kullanmak için, birincisinin portu 1111 diğerinin ise 2222 olan iki adet soket açalım. Ardından Client'ı çalıştırdığımız girdiğimiz paramtreye göre hangi Server soketine veri gönderdiğini konsolda görelim.

server.c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include <WinSock2.h>

DWORD WINAPI server1(void* bos)
{
    struct sockaddr_in server1Addr;
    int server1Soc;

    server1Soc = socket(AF_INET, SOCK_STREAM, 0);

    server1Addr.sin_addr.S_un.S_addr = inet_addr("127.0.0.1");
    server1Addr.sin_family = AF_INET;
    server1Addr.sin_port = htons(1111);

    bind(server1Soc, (struct sockaddr*)&server1Addr, sizeof(server1Addr));

    listen(server1Soc, 5);

    int client1Soc;
    char veri[1024];

    while(1)
    {
        client1Soc = accept(server1Soc, NULL, NULL);

        memset(veri, 0, 1024);
        recv(client1Soc, veri, 1024, 0);

        printf("1. Server'den veri geldi: \"%s\"\n", veri);
    }
}

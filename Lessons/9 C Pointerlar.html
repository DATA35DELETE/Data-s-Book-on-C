Pointerlar

Pointer Nedir?

Türkçesiyle işaretçi anlamına gelen Pointer, bir yapının bellekdeki adresiyle ilgili işlem yapmamızı sağlayan bir araçtır.
İlk olarak bellek adresi nedir onu amlatalım. Her bir yapının RAM'da tutulduğu her adrese bellek adresi denir. Bunu evinizin adresi olarak düşünebilirsiniz. Aynı sizin gibi yapılarında bir bellek adresleri vardır.
Peki neden bellek adresine ihtiyaç duyalım ki? Bu soruyu bir kargocuya "Senin neden bir ev adresine ihtiyacın var ki?" demekle eş değerdir. Çünkü yapıcağımız işlemlerin hangi değişkene yapılması gerektiğini program bilemez. İşte bu durumlar için bellek adresleri vardır. C programalama dilinde değişkenlere bir işlem yapıldığında genelde onun kopyası üzerine yapılır. Ama bazı durumlarda direkt orjinalin üstünde işlem yapmamız gerekir. Daha görmedik ama örnek olarak fonksiyonlarda paramtre gönderim örneğini verebiliriz. Paramtre yani bir değişken gönderirken fonksiyonlara, gönderilen değişkenin kopyasını göndermiş oluruz. Bu durum orjinali üzerinde işlem yapmamızı engeller niteliktedir. Bu sebeble bellek adresleri kullanılır.

Pointer Tanımlama

İşaretçiler için iki araca ihtiyaç duymaktayız. yıldız(*) ve ampersand(&) işaretleri kullanılır.Ampersend, kullanılan yapının adresini verirken yıldız ise o bellek adresindeki değere ulaşmak veya değiştirmek için kullanılır.
Şimdi ise ufak bir örnek yapalım. İki adet değişken tanımlayalım. Biri normal int türünde diğeri ise öncekinin adresini tutucak Pointerlı int türünde. Pointerlı olanı üzerinde işlemler yapalım ve ekrana Pointersız olanı bastıralım.
#include <stdio.h>

int main(){

    int sayi1 = 5;
    int *sayi1ptr = &sayi1; // Bu kısımda sayi1'in bellek adresini sayi1ptr'ye atamış olduk

    printf("sayi1 = %d\n", sayi1);

    *sayi1ptr = 15; // Bellek adresi üzerinden veri atama
    printf("sayi1 = %d\n", sayi1); // Yapılan değişikliği inceleme

    *sayi1ptr += 20; // Bellek adresi üzerinden veri değiştirme
    printf("sayi1 = %d", sayi1); // Yapılan değişikliği inceleme
}

Sırayla konsolda; "5", "15" ve "35" çıktılarını vericektir.

Pointer Aritmetiği

Pointer aritmetiği, Pointer olan bir değişkeni artırma veya azaltma işlemlerine denir.
Bu sistem biraz karmaşık gözüksede aslında dizilerin var olmasını sağlayan önemli bir araçtır. Dizideki veriler aslında bellek sıralanmış şeklinde güzükmektedirler. Örneğin, bir Integer türünde üç elemanlı bir dizimiz olsun. Dizimizin sıfır Index'li elemanın bellek adresi ise "1000" olarak düşünürsek, birinci Index'li elemanın bellek adresi ise "1004" olmalıdır.
Teorik olarak anlatığımız örneğimizi pratiğe dökelim...
#include <stdio.h>

int main(){

    int sayilar[] = {10,20,30};
    int *sayilarPtr = sayilar; // sayilar'ın Pointer'ini atama

    printf("0. Index: %d\n0. Index Bellek Adresi: %p\n", *sayilarPtr, &sayilar[0]); // 10
    printf("1. Index: %d\n1. Index Bellek Adresi: %p\n", *(sayilar + 1), &sayilar[1]); // 20
    printf("2. Index: %d\n2. Index Bellek Adresi: %p", *(sayilar + 2), &sayilar[2]); // 30
}

Derleyim çalıştırdığımız da bu ekran görüntüsüne benzer bir görüntü görmeliyiz.
Ekran görüntüsünde de olduğu gibi bellek adresileri artı dört şeklinde artmaktadır.

Char Dizisinde Pointer Aritmetiği

Integer dizisinden farkı yoktur. Sadece dört dört artmak yerine bir bir artmaktadır bellek adresleri
Integer veri türüd dizisi için verdiğimiz örneği bir String ifadede yani Char veri türü disinde uygulayalım.
#include <stdio.h>

int main(){

    char harfler[] = "abc";
    char *harflerPtr = harfler; // harfler'in Pointer'ini atama

    printf("0. Index: %d\n0. Index Bellek Adresi: %p\n", *harflerPtr, &harfler[0]); // a
    printf("1. Index: %d\n1. Index Bellek Adresi: %p\n", *(harflerPtr + 1), &harfler[1]); // b
    printf("2. Index: %d\n2. Index Bellek Adresi: %p", *(harflerPtr + 2), &harfler[2]); // c
}

Derleyim çalıştırdığımızda;
Benzer bir görüntü karşımızda olucaktır.

Fonksiyonlarda Pointer Kullanımı

Aynı dizeler ve değişkenler gibi fonksiyonlarda da bellek adresi vardır. Dolayısıyla Pointer kullanımı vardır.
Bu durumu ufak bir örnek ile anlatalım. Bir fonksiyonu hem normal hem de Pointer'lı halini kullanalım. Fonksiyonlar konusuna geldiğimizde daha iyi anlıcaksınızdır fakat bu sayfadaki çok kapsamlı olduğundan değinmeden geçemem.
#include <stdio.h>

int selamla(){
    printf("Hello!\n");

    return 0;
}
// Bu fonksiyon ekrana "Hello!" yazdırmaktadır

int main(){

    selamla(); // Noormal fonksiyon çağrısı

    int (*selamlaPtr)() = &selamla; // Tanımlıyoruz

    selamlaPtr(); // Pointer'lı fonksiyon çağrısı
}

Çıktımız iki türlü fonksiyon çağrısı içinde aynı olucaktır.

Callback Fonksiyonlar

Callback Fonksiyon, bir fonksiyonun parametresine başka bir fonksiyonun Pointer'ını göndermek demektir.
Bu tanım biraz anlamsız kalsada ilerki konularda daha iyi anlışılak olucaktır.
Şöyle bir örnek yapalım, iki adet fonksiyon olsun. Birinci fonksiyon bir selamlama fonksiyonu olsun, ikinci ise bir Callback fonksiyon olsun ve paramtresine verilen fonksiyonu çağırsın.
#include <stdio.h>

int selamla(){

    printf("Selamlar...");

    return 0;
}

int fonksiyonCalisitir(int (*fonk)()){

    fonk();

    return 0;
}

int main(){

    fonksiyonCalisitir(selamla); // Paramtre olarak selamla fonksiyonunu gönderdik.
    
    return 0;
}

Çıktımız "Selamlar..." olucaktır.

Double Pointer

Double Pointer kullanımı, bir Pointer'ı Pointer'lamak için kullanılır.
İlk örneğimizi şimdi Double Pointer ile yapalım.
#include <stdio.h>

int main(){

    int sayi1 = 5;
    int *sayi1ptr = &sayi1; // Bu kısımda sayi1'in bellek adresini sayi1ptr'ye atamış olduk
    int **sayi1ptr2 = &sayi1ptr; // Bu kısımda sayi1ptr'in bellek adresini sayi1ptr2'ye atamış olduk

    printf("sayi1 = %d\n", sayi1);

    **sayi1ptr2 = 15; // Bellek adresi üzerinden veri atama
    printf("sayi1 = %d\n", sayi1); // Yapılan değişikliği inceleme

    **sayi1ptr2 += 20; // Bellek adresi üzerinden veri değiştirme
    printf("sayi1 = %d", sayi1); // Yapılan değişikliği inceleme
}

Derlediğimiz zaman kodumuzu aynı çalışıcaktır. Sadece tek Pointer yerine Double Pointer kullandık.

NULL Pointer

NULL Pointer ise hiç bir bellek adresine atanmamış bir Pointer'dır. Bu yapıyı daha çok olasılığa bağlı(Örneğin; Dosya oluşturma) işlemlerde, eğer işlem başarısız olursa NULL Pointer ile kontrol amaçlı kullanılır. Çünkü başarızsız işlemler NULL Pointer sonucunu vermektedir.
Daha görmedik ama bu durumu anlatmak için bir dosya oluşturma ve okuma kodu yazalım...
#include <stdio.h>

int main(){

    FILE *file1 = fopen("yeni.txt", "a"); // Dosyamızı Oluşturuyoruz...
    if (file1 == NULL) // Başarılı olmazsa
        printf("Dosya olusturulamadi...\n"); // Bildir
    else // Başarılı olduysa
        printf("Dosya olusturuldu...\n"); // Bildir

    fclose(file1); // Bellek yönetimi için kapatıyoruz...
    
    FILE *file2 = fopen("olmayanbirdosya", "r"); // Olmayan bir dosyayı açmaya çalışıyoruz...
    if (file2 == NULL) // Başarılı olmazsa
        printf("Dosya acilamadi...\n"); // Bildir
    else // Başarılı olduysa
        printf("Dosya acildi...\n"); // Bildir

    fclose(file2); // Bellek yönetimi için kapatıyoruz...
}

derleyip çalıştıralım ve sonuçları görelim.

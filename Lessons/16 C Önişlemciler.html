Önişlemciler

Önişlemci Nedir?

Önişlemci, program derlenmeden önce bir aşaması olan önişleme kısımdaki koşula göre kodun derlenecek kısımlarının belirlendiği yapılardır. Sonlarında noktalı virgül konulmamaktadır.
Giriş sayfasında da anlattığımız gibi önişlemciler bizlere bir nevi "tüm platformlar tek kod" metodu sunar. Yani kaynak kodu hem Windows hem de Linux için kodları içerir fakat önişlemciler sayesinde hangi işletim sistemi bulunursa, ona yönelik olan kod derleme sürecine girer. Diğer kod ise derlenme sürecine girmez.

Include

Include, kaynak koduna hazır olarak yazılmış veya kendimizin yazdığı bağlık dosyaları(Headrs olarak bilinir) eklemizi sağlar. Sıkça benzettiğim "Kütüphane ekleme" teriminin ilkel halidir.
İki şekilde Include kullanılabilir. Küçüktür ve büyüktür içerisinde dosya ismini belirtme ve çift tırnaklar içerisine dosya adı belirtme şeklindedir.

Küçüktür ve büyüktür ile Include

Dosyayı ana "Include" adlı bir klasörde arar.
#include <stdio.h>
// Merak ederseniz eğer Mingw64 klasörün içerisindeki Include adlı klasörün içinde stdio.h dosyasını görebilirsiniz

Çift Tırnaklar ile Include

Diğerinde farkı ise dosyayı ana Include klasöründense kaynak kodunun bulunduğu dizinde arar. Kendi yazdığımız başlık dosyalarını çift tırnaklı Include içerisinde tanımlayabiliriz.
#include "benimBaslikDosyam.h"

Define

Değişkenler sayfasında gördüğümüz ve sabit değişken tanımlamanın başka bir türü olduğunu bildiğimiz Define'nın kullanım amacı ise "makro" denilen ve sık kullanılan değerleri direk değişken isimleriyle çağırmamızı sağlamaktadır. Bu bir zorunluluk değildir fakat diğer normal ve sabit değişkenlerle karışmasın diye büyük harfle yazılır.
#define DEGER_ISMI DEGER
//Türü belirtilmez çünkü C tarafından otomatik en uygun veri türü atanır

Koşullu Derleme

Koşulle derleme ise bahsettiğimiz gibi belirli koşullarda bazı kodları derleme bazılarını es geçmek için kullandığımız bir yapıdır. Genellikle tek kodu tüm platformlarda çalıştırmak için kullanılır. 
#ifdef, makro tanımlıysa kodu kat.
#ifndef, makro tanımlı değilse kodu kat.
#endif, ifdef ve ifndef sonunu bildirir.
#else, hiç biri anlamına göre kodu katar.
İşletim sistemlerinin başlık dosyalarında her zaman kendi işletim sistemlerini belirten bir makro değeri vardır. Genellikle C kodları Windows ve Linux işletim sistemlerinde kodlandığı için derleme modeli "Windows mu değil mi" şeklinde gider. Windows işletim sisteminin makrosunun ismi ise WIN32'dir.
Şimdi ise eğer Windows işletim sisteminde derlendiyse konsola "Windows'dayim", Windows dışı bir işletim sisteminde derlendiyse ise de "Windows'da değilim" yazan bir kod yazalım.
#include <stdio.h>

int main()
{

    #ifdef WIN32 // Windows işletim sistemiyse eğer

    printf("Windows'dayim\n");

    #else // Windows işletim dışı bir sistemdeyse

    printf("Windows'da değilim\n");

    #endif

    return 0;
}

Sırasıyla Windows ve Linux çıktıları

Başlık Dosyaları

İngilizcesiyle Headers, kendi kod içi kütüphanemizi oluşturuken kullandığımız bir dosya formatıdır.
Başlık dosyaları, kendi isimleriyle isimlendirelen ve .c uzantılı dosyanın diğer kaynak dosyalarına kodlarını paylaşmasını sağlar. C kaynak kodunda fonksiyon yazılırken, H kaynak kodunda ise fonksiyonların gövdesiz halini halini yazılır.
Eğer bir program içerisinde iki kere başlık dosyasını çağırma durumunda derliyiciler hata vermektedir. Çünkü tanımlanan bir dosyayı tekrar tanımlamak hem bilgisayarın hem de derliyicinin kafasını karıştırmaktadır. Aynı bir değişkeni tekrar sanki ilk defa tanımlıyomuş gibi yapmak gibi... Bu durumu önlemek için #ifndef, #define ve #endif ile tekrar tanımlama önlenir.
Derleme yapılırken ise sürece diğer dosyalarda katılır. Aksi taktirde hata vericektir.
Şimdi ise 3 adet dosya oluşturalım. main.c, topla.c ve topla.h olsun. main.c içerisinde topla.c'nin "topla" fonksiyonun topla.h ile erişelim ve ekrana yazdıralım.
main.c
#include <stdio.h>
#include "topla.h" // Kütüphanemiz

int main(){

    printf("2 + 2 = %d", topla(2, 2)); // Kullanımı

    return 0;
}

topla.h
#ifndef _TOPLA_H // Eğer _TOPLA_H isimli bir macro tanımlanmadıysa
#define _TOPLA_H // Tanımla

int topla(int a, int b); // topla.c'deki fonksiyonun gövdesiz hali

#endif

topla.c
int topla(int a, int b) // Fonksiyonumuz
{
    return a + b;
}

Çıktımız ise "2 + 2 = 4" şeklinde olucaktır.

Makro Fonksiyonlar

Makro fonksiyonlar, aynı normal makrolar gibi tanımlanır ve değer verilir. Inline yani normal fonksiyonlar arasındaki fark ise yazılan fonksiyon isminin direkt fonksiyonun içerisindeki işleme bellekte dönüşür.
Başlık dosyası örneğimizi makro fonksiyonlar ile yapalım.
#include <stdio.h>

#define TOPLA(a, b) a+b // Makrı fonksiyonumuz

int main(){

    printf("2 + 2 = %d", TOPLA(2, 2)); // Kullanımı

    return 0;
}

Çıktısı aynı olucaktır.

Önceden Tanımlı Makrolar

C içerisinde önceden tanımlı olan bazı makrolar vardır. Bazıları;
Makro Açıklama
__FILE__ Çalıştığı C kaynak kodunun ismini verir. Char dizesi verir.
__TIME__ Derlendiği saati Char dizesi verir.
__DATE__ Derlendiği tarihi Char dizesi verir.
__STDC_ Kodlanan C kodunu derleyem derliyici C standartlarına uyuyor mu? Uyuyorsa bir değil ise sıfır.
__LINE_ Çağrılan satırı >Int türünde değeri döndürür. 
Şimdi ise bu makroları içeren bir program yazalım.

#include 

int main(){

    printf("Tarihi ve saat: %s %s\n", __DATE__, __TIME__);
    printf("Calisan C kaynak kodu ismi: %s\n", __FILE__);
    printf("Bu program C standartlarina uygun mu? Cevap, %s\n", __STDC__ ? "evet" : "değil");
    printf("Bu mesaji yazdiran kodun satiri: %d", __LINE__);

    return 0;
}
